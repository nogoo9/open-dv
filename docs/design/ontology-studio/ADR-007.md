# ADR-007: ONT-EVO Contract Guard Rules (`ONT-EVO-001..003`)

## Status
Proposed

## Context
Graph A drives physical tables (`hub_*`, `lnk_*`, `sat_*`, `ref_*`). Contract guards prevent warehouse breakage, lost updates, and ungrounded identifiers via OCC.

## Decision
`opendv_core.ontology.structural_validator` validates structural invariants; op dispatch, reference pack lookup, permissions, EvidenceRef verification, and SemVer bumping live in `opendv_service.ontology.governance_validator`. Layering: `opendv_core` never imports `opendv_contracts`, `opendv_sources`, or `opendv_service`.

### 1. `ONT-EVO-001`: Immutability & Deployed Contract Protection
- **Committed Version Immutability**: Committed versions are immutable with `parent_sha256` lineage.
- **Deterministic Table Derivation & Collision Guards**: Via `PipelineContractRegistryPort`: `canonical_slug(raw)` lowercases, `-` $\to$ `_` (`^[a-z0-9][a-z0-9_]*$`, $\le 55$; $> 55$ -> `INVALID_PHYSICAL_TABLE_NAME` 422 exit 4; collision `PHYSICAL_TABLE_NAME_COLLISION`). `RenameConceptOp` BLOCKed over deployed `hub_*`. Overrides: `target_hub`, `target_link`, `target_reference_table` ($\le 63$). Prefixes: `hub_`, `sat_`, `hal_`, `lnk_`, `t_lnk_`, `ref_`. Unmapped: `UNDEFINED_PHYSICAL_TABLE_MAPPING` (exit 4).
- **Deployed Artifact Matrix (All 23 Ops Covered)**:
  - **BLOCK (`ONT_EVO_CONTRACT_VIOLATION` exit 4)**: 9 destructive (`DeleteConceptOp`, `RenameConceptOp`, `ReparentConceptOp`, `ClearParentConceptOp`, `RemoveAttributeOp`, `DeleteRelationshipOp`, `DeleteEnumerationOp`, `RemoveEnumerationCodeOp`, `ChangeDomainNamespaceOp`); non-optional `AddAttributeOp` on deployed `sat_*`. Referenced delete fails `CONCEPT_STILL_REFERENCED` (exit 4).
  - **PERMIT**: 4 destructive (`ReviseDescriptionOp`, `RepinExternalMappingOp`, `RemoveExternalMappingOp`, `RemoveSynonymOp`); 10 additive `AddConceptOp`..`RescoreExternalMappingOp` (optional `AddAttributeOp` permitted).
- **State-Based Check (`validate_deployed_contract_compatibility`)**: Deployed `hub_*`/`lnk_*` retain keys, `sat_*` retain columns (`is_optional=True`), `ref_*` retain codes (`ONT_EVO_CONTRACT_VIOLATION` exit 4).

### 2. `ONT-EVO-002`: Positive Grounding, Referential Integrity & Anti-Silo
- **Layered Validation & Grounding Invariants**: Strict architectural split:
  - **Core-Owned (`opendv_core.ontology.structural_validator`)**: Structural checks taking primitive `touched_concept_uris: frozenset[str]` and `grandfathered_concept_uris: frozenset[str]` (service-computed; grandfathered seed concepts exempt while untouched; legacy concepts failing `_CU` read-only, addressing in delta ops fails `SYNTAX_INVALID_ARGUMENT` exit 2): URI grammar (`_CU`, `_E`, `_RU`; ungrounded `ONT_EVO_GROUNDING_VIOLATION` 422 exit 4), 1:1 Hub bijection, table collisions, referential integrity, reserved-token scans (`PROVISIONAL_URI_PATTERN = r"(?i)urn:opendv:provisional:"` [`ONT_EVO_GROUNDING_VIOLATION` commit, `IMPORT_PROVISIONAL_URI_FORBIDDEN` import], `[REDACTED_ODV_*]`; unwaivable). Ports: `ReferencePackLookupPort`, `GroundingResultPort`, `PseudonymScrubberPort`.
  - **Service-Owned (`opendv_service.ontology.governance_validator`)**: Business invariants: pack lookup (`UNKNOWN_REFERENCE_PACK` exit 4), membership/labels (`ONT_EVO_GROUNDING_VIOLATION` exit 4), BM25 Server Grounding, CAS verification, HMAC pseudonym detection via `PseudonymScrubberPort`, provenance (`ONT_EVO_FORGED_PROVENANCE` exit 4; closure `subClassOf` exempt). Proposed ONT-EVO-002 Amendment (pending Phase 4A human sign-off; `contracts-freeze-gate` blocks `Accepted` status until signed amendment record exists with approver, date, commit): Touched concepts must satisfy: (1) Default: >= 1 non-subClassOf registered-pack mapping >= 0.65; (2) Admin waiver (`low_confidence_grounding_waiver=True`): >= 1 non-subClassOf mapping < 0.65 with admin rationale (>= 10 chars); (3) Evidence grounding: zero external mappings permitted iff admin CAS snippet `evidence_grounding` present (`INVALID_EVIDENCE_OFFSETS` exit 2, `INVALID_EVIDENCE_GROUNDING` exit 4). Grandfathered seed concepts (`grandfathered_concept_uris`) are an explicitly ratified legacy exception exempt while untouched; waiver set re-checked on promotion. Zero mappings and zero evidence is strictly ungrounded (`ONT_EVO_UNGROUNDED_CONCEPT` exit 4), never waivable. Term-set mutations (`TERM_SET_MUTATION_OPS`: `AddConceptOp`, `RenameConceptOp`, `AddSynonymOp`, `RemoveSynonymOp`) append `RescoreExternalMappingOp`s to `delta.ops`; `apply()` is pure. Import replay re-scores verify-only (`IMPORT_CONFIDENCE_MISMATCH` exit 4); low confidence requires `--acknowledge-unverified-import-attribution --acknowledgement-rationale <t>`.
- **Pseudonym & Placeholder Leak Guard**: `ONT_EVO_PSEUDONYM_LEAK` and `REDACTED_PLACEHOLDER_LEAK` (422 exit 4) scan all string fields (URIs, IDs, slugs, placeholders); matches raise `AGENT_UNRESOLVED_PSEUDONYM`/`ONT_EVO_PSEUDONYM_LEAK`. Masks use `[REDACTED_ODV_*]`. De-pseudonymization runs on raw JSON before proposal creation.
- **Structural Anti-Silo & Hierarchy**: 1:1 Hub bijection (`HUB_BIJECTION_VIOLATION`), table collisions (`PHYSICAL_TABLE_NAME_COLLISION`), referential blocks (`CONCEPT_STILL_REFERENCED`, `REFERENCED_CONCEPT_NOT_FOUND`, `PARENT_NOT_FOUND`, `ATTRIBUTE_NOT_FOUND`, `MAPPING_NOT_FOUND`, `RELATIONSHIP_NOT_FOUND`, `ENUM_CODE_NOT_FOUND` exit 4). `parent_concept_uri` points in-ontology; external parents ground as `ExternalMapping(mapping_type="subClassOf")` requiring grounded non-subClassOf mapping. `SetParentConceptOp` requires parent `None` (`PARENT_ALREADY_EXISTS` exit 4; reparenting uses `ReparentConceptOp`). `AGENT_METADATA_OVERWRITE_FORBIDDEN` (exit 7) precedes `*_ALREADY_EXISTS`; `SetDescriptionOp` on populated description fails `DESCRIPTION_ALREADY_EXISTS` (revising uses `ReviseDescriptionOp`, admin). DAG check (`HIERARCHICAL_CYCLE_DETECTED` exit 4). Destructive ops require `reason` and admin (`FORBIDDEN_ADMIN_REQUIRED` exit 7).

### 3. `ONT-EVO-003`: Optimistic Concurrency Control, Rebase & Error Registry
- **Canonical Error Precedence (authoritative across REST & CLIs)**: 0. CLI-Local Flag/Syntax Validation (`SYNTAX_INVALID_ARGUMENT` exit 2) -> 1. AuthN (401 exit 7) -> 2. Precondition Syntax (`MISSING_PRECONDITION_HEADER`, `INVALID_PRECONDITION_HEADER` exit 2) -> 3. RBAC (`FORBIDDEN_ADMIN_REQUIRED`, `AGENT_OPERATION_FORBIDDEN` 403 exit 7) -> 4. Body Parse / Uniqueness (syntax wins 400 exit 2: `SYNTAX_INVALID_ARGUMENT`, `MISSING_AUTO_COMMIT_PRECONDITION`; else location uniqueness fires 422 exit 4: `DUPLICATE_*`, `DUPLICATE_ENUM_CODE`, `DUPLICATE_RELATIONSHIP_URI`, `AMBIGUOUS_EXTERNAL_MAPPING`, `DANGLING_ENUM_CODE_DESCRIPTION`) -> 5. Envelope (`ONT_EVO_ENVELOPE_VIOLATION` 422 exit 4; automated destructive construct emits SSE `AGENT_DESTRUCTIVE_OP_FORBIDDEN` exit 7) -> 6. Lifecycle (`PROPOSAL_ALREADY_RESOLVED` 409 exit 6) -> 7. Field Auth (non-admin waiver/revision fails exit 7 before exit 4: `FORBIDDEN_ADMIN_REQUIRED`, `AGENT_ADMIN_OP_FORBIDDEN`) -> 8. Semantic Waiver (`INVALID_GROUNDING_WAIVER` 422 exit 4) -> 9. Precondition/OCC (`body.base_sha256 != head_sha256` -> `ONT_EVO_CONCURRENT_MODIFICATION` 412 exit 5; sha/version mismatch -> `PRECONDITION_BASE_SHA_MISMATCH` exit 2) -> 10. Referential/ONT-EVO (`ONT_EVO_UNGROUNDED_CONCEPT` 422 exit 4, `NO_OP_DELTA` 400 exit 1). Tests assert Step 0 exits 2, Step 3 exits 7.
  - **Commit Preconditions**: Under `.session.lock`: (a) `If-Match` vs `body.base_sha256` (mismatch 400 `PRECONDITION_BASE_SHA_MISMATCH` exit 2); (b) Concurrency OCC: `body.base_sha256 != session.head_sha256` (412 `ONT_EVO_CONCURRENT_MODIFICATION` exit 5); (c) Version-SHA consistency: `base_version != session.active_version` (400 `PRECONDITION_BASE_SHA_MISMATCH` exit 2). Proposal accept: (1) `If-Match != body.base_sha256` (exit 2); (2) `body.base_sha256 != session.head_sha256` (exit 5); (3) `proposal.base_sha256 != session.head_sha256` (exit 5); (4) `proposal.base_version != session.active_version` (exit 2). Revisions require admin (`FORBIDDEN_ADMIN_REQUIRED` exit 7).
  - `POST /sessions/{id}/promote` (Workspace OCC & Lock): `graph_a.lock` -> `.session.lock`: `compute_workspace_sha256(ws)` ("0"*64 if empty, else `compute_ontology_sha256(validate_graph_a(ws))`). Steps: (0) `OPENDV_WORKSPACE_ROOTS` containment (`INVALID_WORKSPACE_PATH` exit 2; remote rejects `server_path` `REMOTE_SERVER_PATH_FORBIDDEN` exit 2); (1) `X-OpenDV-Workspace-If-Match == body.workspace_sha256` (exit 2); (2) Workspace OCC: `compute_workspace_sha256(ws) == body.workspace_sha256` (stale exit 5; greenfield empty ws, genesis lineage, head >= 1.0.0; seeded requires edits, `NO_OP_DELTA` exit 1; mismatch `ONT_EVO_CONTRACT_VIOLATION` exit 4); (3) Session OCC: `If-Match == head_sha256` (stale exit 5); (4) Lineage: `body.workspace_sha256 in session.lineage(head) | {seed_source_sha256}` (greenfield `"0"*64` accepted iff genesis lineage; else `LINEAGE_ROOT_MISMATCH` exit 5); (5) `validate_deployed_contract_compatibility` (`ONT_EVO_CONTRACT_VIOLATION` exit 4; warnings require `acknowledge_historical_contract_warning=True` [unack `HISTORICAL_CONTRACT_WARNING_UNACKNOWLEDGED` exit 4, acknowledged requires rationale >= 10 chars, missing/blank `HISTORICAL_CONTRACT_RATIONALE_REQUIRED` exit 1]; missing CLI `--rationale` flag fails Step 0 exit 2, blank/empty rationale fails `PROMOTION_RATIONALE_REQUIRED` exit 1); (6) Re-asserts ONT-EVO-002: >= 1 non-subClassOf registered-pack mapping >= 0.65 OR admin waiver `low_confidence_grounding_waiver=True` (imported requires `acknowledged_attribution=True`) OR verified `evidence_grounding` (zero fails `ONT_EVO_UNGROUNDED_CONCEPT` exit 4; grandfathered seed concepts in `grandfathered_concept_uris` exempt while untouched); (7) Writes head atomically under `graph_a.lock` (containment, staged, fsync, `os.replace`).
  - `POST /sessions/{id}/construct`: `auto_commit=True` requires `If-Match == body.base_sha256` at submission (exit 2) and re-verifies `head_sha256 == base_sha256` under `.session.lock` at commit (412 exit 5; terminal SSE event); `auto_commit=False` has optional `If-Match`; body pins base version/sha.
  - `POST /sessions/{id}/proposals/{pid}/reject`: Takes `.session.lock`, requires `proposal.status == "PENDING"` (resolved -> HTTP 409 `PROPOSAL_ALREADY_RESOLVED`, exit 6), marks `REJECTED`.
- **Proposal Rebase & Conflict Specification**: `POST /sessions/{id}/proposals/{pid}/rebase` takes optional `If-Match: "<proposal.base_sha256>"` under `.session.lock`, requiring `proposal.status == "PENDING"` (resolved -> 409 `PROPOSAL_ALREADY_RESOLVED` exit 6; mismatch -> 400 `PRECONDITION_BASE_SHA_MISMATCH` exit 2). Conflicts (412 exit 5) evaluated per ADR-006 §4.3 read/write keys; clean rebase updates base version and sha.
- **Precondition Syntax & Error Registry**: `If-Match: *` and weak ETags (`W/"..."`) reject HTTP 400 `INVALID_PRECONDITION_HEADER`. `schemas/v1/error-codes.json` and ADR-012 §4 govern exit codes 0..7.

## Consequences & Compliance
Eliminates race conditions; enforces grounding, acyclicity, deployed safety, and error codes. Tests verify OCC, cycle detection, token rejection, and contract violations.
