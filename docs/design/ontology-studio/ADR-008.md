# ADR-008: In-Memory Okapi BM25 Concept Matching SPI

## Status
Proposed

## Context
Mapping extracted terms to reference ontologies requires fast, deterministic scoring without external vector stores or remote embedding API costs in offline CI.

## Decision
We define a pluggable `ConceptMatcher` SPI in `opendv_service.ontology.matching` and implement `Bm25ConceptMatcher` as the default engine:

### 1. `ConceptMatcher` SPI Specification
DTOs in `opendv_contracts.dtos.matching`; SPI in `opendv_service.ontology.matching`:
```python
from abc import ABC, abstractmethod
from pydantic import Field
from opendv_contracts.dtos.base import BaseContractModel

_DFL = Field(default_factory=list)
class ReferenceConcept(BaseContractModel): concept_uri: str; concept_name: str; module: str; definition: str = ""; synonyms: list[str] = _DFL; parent_concept_uris: list[str] = _DFL
class ScoredConceptMatch(BaseContractModel): concept_uri: str; concept_name: str; module: str; raw_score: float; normalized_score: float; matched_term: str; definition: str

class ConceptMatcher(ABC):
    @abstractmethod
    def index_concepts(self, concepts: list[ReferenceConcept]) -> None: ...
    @abstractmethod
    def match(self, query: str, top_k: int = 5, module_filter: list[str] | None = None, min_score: float = 0.0) -> list[ScoredConceptMatch]: ...
    @abstractmethod
    def score(self, query: str, concept_uri: str) -> ScoredConceptMatch | None: ...
```

### 2. Multi-Field Okapi BM25 Formulation & Normalization
- **Parameters & Tokenization**: $k_1 = \text{Decimal}("1.5")$, $b = \text{Decimal}("0.75")$. Tokenizer uses pinned Unicode 14.0 character tables versioned inside `matcher_sha256 = sha256(JCS(spec))` in `bm25_fibo_v1.json` (vectors in `bm25.json`), ensuring deterministic cross-Python (3.11+) execution; unpinned runtime divergence fails closed `MATCHER_UNIDATA_VERSION_MISMATCH` (500 exit 1). 7-step tokenization: (1) NFC; (2) CamelCase split; (3) Delims `[_\-\s]+`; (4) Words `[^\W_]+`; (5) Lowercase; (6) 18 financial acronyms (`acct`$\to$`account`); (7) 33 stopwords.
- **Fixed-Precision Decimal Arithmetic**: Robertson IDF $\text{IDF}(t) = \ln(1 + (N - n + 0.5) / (n + 0.5))$, TF saturation $\text{TF}(t, D) = \frac{\text{freq} \cdot (k_1 + 1)}{\text{freq} + k_1 \cdot (1 - b + b \cdot |D| / \text{avgdl})}$, and combinations run under Decimal `Context(prec=28)`. `avgdl`, `N`, `n` are per field (`BM25(field) = Decimal("0.0000")` if `avgdl == 0` or `freq == 0`); `BM25(C.synonyms, Q)` concatenates synonyms.
- **Empty & OOV Query Guard**: Out-of-vocabulary words are dropped before scoring; if query tokens are empty, `match()` returns `[]` and `score()` returns `ScoredConceptMatch` with `0.0000` scores (or `None` if concept not in pack).
- **Module Filter Precedence**: `module_filter` evaluates during document traversal before sorting/slicing `top_k`.
- **Multi-Field Linear Combination**:
  $\text{Score}(C, Q) = 2.5 \cdot \text{BM25}(C.\text{name}, Q) + 2.0 \cdot \text{BM25}(C.\text{synonyms}, Q) + 1.0 \cdot \text{BM25}(C.\text{definition}, Q)$
- **Normalization, Direct Concept Scoring & Deterministic Tie-Breaking**:
  Sorts by `(-normalized_score, -raw_score, concept_uri)` on Decimals, float in DTOs. $Q_{\text{self}} = C.\text{name}$. $\text{Score}(Q, Q) = 2.5 \cdot \text{BM25}(Q, Q)$ against name statistics ($\text{avgdl}=\text{avgdl}(\text{name})$). $\text{NormalizedScore}(C, Q) = \min(1, \text{Score}(C, Q) / \max(\text{Score}(C, C.\text{name}), \text{Score}(Q, Q))) \text{ if } \max(\text{Score}(C, C.\text{name}), \text{Score}(Q, Q)) > 0 \text{ else } \text{Decimal}("0.0000")$ (symmetric in `bm25.json`). `ScoredConceptMatch.normalized_score` holds 4-decimal quantized Decimal as float; `ExternalMapping.confidence = normalized_score`. Aggregates over `[name] + synonyms` as $\max_{t} \text{score}(t, \text{standard\_uri})$. Term-set mutations (`AddConceptOp`, `RenameConceptOp`, `AddSynonymOp`, `RemoveSynonymOp`) append server-generated `RescoreExternalMappingOp`s to `delta.ops`; `apply()` is pure. Import replay re-scores verify-only checking recorded `new_confidence` (closure `subClassOf` 1.0; mismatch `IMPORT_CONFIDENCE_MISMATCH` exit 4; < 0.65 without waiver rejects `ONT_EVO_LOW_CONFIDENCE_GROUNDING` 422 exit 4). Gate: `normalized_score >= 0.65` requires hit on name or synonym ($\text{BM25}(C.\text{name}, Q) > 0 \lor \text{BM25}(C.\text{synonyms}, Q) > 0$); else capped at `0.6400`, preventing false grounding. Direct `score()` uses identical pipeline.
- **Matcher Versioning & Immutability**: `matcher_id = "bm25_fibo_v1"`, `matcher_version = "1.0.0"`, `matcher_sha256 = sha256(JCS(matcher_spec))` in `schemas/v1/matchers/bm25_fibo_v1.json` (vectors in `bm25.json`). Index scoped per pack (`reference_pack_sha256`). Identity is `(matcher_sha256, reference_pack_sha256)` in `VersionMetaRecord`. Import replay matches `matcher_sha256` against `Bm25MatcherRegistry` (missing `IMPORT_MATCHER_VERSION_MISMATCH` 422 exit 4; verify-only).

### 3. Agent Integration & Taint Boundary
In Agent Mode, top-20 matches feed `@ontology-architect`. Tainted queries (`do_not_send_to_agent=True`) run server-side; `matched_term` scrubs to `"[REDACTED_ODV_CONFIDENTIAL_SOURCE]"`, and candidates are pseudonymized before presentation (ADR-016).

## Consequences & Compliance
Pure Python in-memory index; calibrated scores; pluggable SPI. Tests verify rank-1 identity for FIBO benchmarks.
