# ADR-006: Additive `OntologyDelta` Operations with Human Edit Versioning Lineage

## Status
Proposed

## Context
Ontology evolution balances agent proposals with human steward revisions governed by cryptographic SemVer lineage.

## Decision
We enforce strict bifurcation between Agent Proposals and Human Edits via typed deltas, separate envelopes, and attribution:

### 1. Discriminated Union of Delta Operations (Authoritative in `opendv_contracts.dtos.ontology`)
All delta items inherit from `BaseContractModel` (`extra="forbid"`, unknown fields -> `SYNTAX_INVALID_ARGUMENT`, 400 exit 2) and declare a distinct `op_type`:

def _norm_desc_target(d: object) -> object:
    if not isinstance(d, dict): return d
    cu, tk = d.get("concept_uri"), d.get("target_kind", "concept")
    raw_tid = d.get("target_id") if d.get("target_id") is not None else (cu if cu is not None else "")
    if not isinstance(raw_tid, str): raise _Err("SYNTAX_INVALID_ARGUMENT", "target_id must be string")
    tid = raw_tid
    if cu and (tk != "concept" or (d.get("target_id") is not None and d["target_id"] != cu)): raise _Err("VALIDATION_AMBIGUOUS_TARGET", "target mismatch")
    _p = {"concept": _CP, "relationship": _RP, "enumeration": _EP}
    if tk in _p and not re.fullmatch(_p[tk], tid): raise _Err("SYNTAX_INVALID_ARGUMENT", "invalid target_id")
    if tk == "ontology" and tid != "": raise _Err("SYNTAX_INVALID_ARGUMENT", "ontology target_id must be empty")
    return {**d, "target_id": "" if tk == "ontology" else tid, "concept_uri": None}

class MutationDeltaRecord(GroundingWaiverMixin):
    record_type: _L["mutation"] = "mutation"; delta_id: _U; base_version: _V; base_sha256: _H; target_version: _V; target_sha256: _H; actor: _L["human"] | _A; author: _P; timestamp: AwareDatetime; operations: list[CommittedDeltaOp] = Field(min_length=1); rationale: str = Field("", max_length=4096); is_steward_revision: bool = False; proposer_actor: _A | None = None; proposer_principal: _P | None = None; accepted_by: _P | None = None; issuance_chain: _PL = _DFL; triggered_by_issuance_chain: _PL = _DFL; triggered_by: _P | None = None; self_acceptance_override: bool = False; commit_mode: _L["delta", "construct", "proposal_accept", "revision"] = "delta"

    @model_validator(mode="after")
    def validate_actor_and_revision(self, info: ValidationInfo) -> Self:
        is_imp = bool(info.context and info.context.get("mode") == "import")
        has_d = any(op.op_type in _D_TYPES for op in self.operations)
        _env = "IMPORT_ENVELOPE_VIOLATION" if is_imp else "ONT_EVO_ENVELOPE_VIOLATION"
        _dst = "IMPORT_AGENT_DESTRUCTIVE_OP_FORBIDDEN" if is_imp else "AGENT_DESTRUCTIVE_OP_FORBIDDEN"
        _adm = "IMPORT_ADMIN_OP_FORBIDDEN" if is_imp else "AGENT_ADMIN_OP_FORBIDDEN"
        bad_trig = (self.commit_mode in ("delta", "revision") and self.triggered_by is not None and self.triggered_by != self.author) or (self.commit_mode in ("construct", "proposal_accept") and not _is_h(self.triggered_by))
        if bad_trig or (self.commit_mode == "revision") != self.is_steward_revision or (self.commit_mode == "proposal_accept") != (self.accepted_by is not None) or (self.commit_mode == "proposal_accept" and self.author != self.accepted_by): raise _Err("ONT_EVO_CONTRACT_VIOLATION", "attribution mismatch")
        if (self.actor == "human" and not _is_h(self.author)) or (self.commit_mode == "delta" and (self.actor != "human" or self.accepted_by is not None)) or (self.commit_mode == "construct" and (self.actor not in ("agent", "deterministic") or not self.author.startswith(f"{self.actor}:"))) or (_is_h(self.author) != (_is_h(self.accepted_by) if self.accepted_by else (self.actor == "human"))): raise _Err("ONT_EVO_CONTRACT_VIOLATION", "attribution mismatch")
        if self.commit_mode != "revision" and has_d:
            if self.actor != "human": raise _Err(_dst, "destructive")
            raise _Err(_env, "revision required")
        if self.is_steward_revision and not has_d: raise _Err(_env, "destructive required")
        if (self.low_confidence_grounding_waiver or self.evidence_grounding) and self.actor != "human": raise _Err(_adm, "automated admin forbidden")
        if self.evidence_grounding and any(not e.approved_by or not _is_h(e.approved_by) for e in self.evidence_grounding): raise _Err("ONT_EVO_FORGED_PROVENANCE", "admin required")
        if bool(self.low_confidence_grounding_waiver) != bool(self.grounding_rationale) or (self.low_confidence_grounding_waiver and len((self.grounding_rationale or "").strip()) < 10) or bool(self.low_confidence_grounding_waiver) != bool(self.low_confidence_waiver_concepts): raise _Err("INVALID_GROUNDING_WAIVER", "invalid waiver")
        if self.accepted_by is not None:
            if not _is_h(self.accepted_by) or not self.proposer_actor or not self.proposer_principal or not self.proposer_principal.startswith(f"{self.proposer_actor}:") or self.actor != "human": raise _Err("ONT_EVO_CONTRACT_VIOLATION", "invalid attribution")
            is_self = bool(self.triggered_by and (self.accepted_by == self.triggered_by or (self.triggered_by_issuance_chain and self.accepted_by in self.triggered_by_issuance_chain)))
            if is_self and (not self.self_acceptance_override or self.accepted_by != LOCAL_ADMIN_PRINCIPAL): raise _Err("ONT_EVO_CONTRACT_VIOLATION", "self acceptance requires override")
            if not is_self and self.self_acceptance_override: raise _Err("ONT_EVO_CONTRACT_VIOLATION", "override forbidden")
        elif self.proposer_principal is not None or self.proposer_actor is not None: raise _Err(_env, "forbidden")
        if self.actor in ("agent", "deterministic") and (not self.triggered_by or self.proposer_actor or self.is_steward_revision): raise _Err("IMPORT_AUTOMATED_ATTRIBUTION_INVALID" if is_imp else "AUTOMATED_ATTRIBUTION_INVALID", "invalid mutation")
        return self

### 2. Server-Enforced Actor Attribution, Envelope Segregation & Validation
Pipeline follows ADR-007 §3 precedence: Step 0 syntax fails exit 2; Step 4 syntax fails exit 2 (`SYNTAX_INVALID_ARGUMENT`; body <= 10MB; ops type URIs with `_CU`); uniqueness (`DUPLICATE_*`, `DUPLICATE_ENUM_CODE`) fails exit 4; non-admin waiver fails Step 7 exit 7 before Step 8 semantic waiver (`INVALID_GROUNDING_WAIVER` exit 4). `canonical_slug` in `opendv_core.canonical` (contracts never imports service/sources). `relationship_uri`: server-derived (`f"urn:opendv:relationship:{canonical_slug(name)}"`; mismatch `VALIDATION_AMBIGUOUS_TARGET` exit 2); unique on name (`DUPLICATE_RELATIONSHIP_NAME` exit 4) and URI (`DUPLICATE_RELATIONSHIP_URI` exit 4). `DeleteRelationshipOp` keys on canonical `relationship_uri: _RU`. `mapping_type=None` on Remove/Repin resolves single match (multiple `AMBIGUOUS_EXTERNAL_MAPPING`, zero `MAPPING_NOT_FOUND` exit 4). `apply()`: pure function of `(base, ops)`: appends additions, preserves order; `RescoreExternalMappingOp` updates confidence. `RescoreExternalMappingOp` is strictly server-generated; client submission fails Step 4 discriminator (`SYNTAX_INVALID_ARGUMENT` exit 2). Server recomputes `ExternalMapping.confidence` via BM25 at commit, ignoring client values. Direct `/delta` requires human (`actor="human"`; automated Step 3 `AGENT_OPERATION_FORBIDDEN` exit 7; destructive `ONT_EVO_ENVELOPE_VIOLATION` exit 4; construct destructive emits `AGENT_DESTRUCTIVE_OP_FORBIDDEN` exit 7). Revisions require `StewardRevisionRequest` (admin exit 7; deployed check `ONT_EVO_CONTRACT_VIOLATION` exit 4). Construct auto-commit sets `author=f"{resolved_mode}:{job_id}"`, `actor=resolved_mode`, `triggered_by=principal` (mismatch `ONT_EVO_CONTRACT_VIOLATION` exit 4). `EvidenceGroundingApproval.approved_by` server-bound (`ONT_EVO_FORGED_PROVENANCE` exit 4). Admin waivers require `low_confidence_grounding_waiver=True`, unique touched concepts subset with >= 1 non-subClassOf registered mapping < 0.65 (zero mappings/evidence fails `ONT_EVO_UNGROUNDED_CONCEPT` exit 4), and `grounding_rationale` ($\ge 10$ chars; non-admin exit 7; mismatch `INVALID_GROUNDING_WAIVER` exit 4); `False` requires concepts `None`. `SetParentConceptOp` requires parent `None` (`PARENT_ALREADY_EXISTS` exit 4). `_norm_desc_target` drops `concept_uri`. `SetDescriptionOp` fails `DESCRIPTION_ALREADY_EXISTS` (exit 4; revising uses `ReviseDescriptionOp`, admin; automated overwrite `AGENT_METADATA_OVERWRITE_FORBIDDEN` exit 7). Cascades: `RemoveEnumerationCodeOp` cascades code_descriptions; `DeleteConceptOp` cascades attrs/syns/mappings (`CONCEPT_STILL_REFERENCED` exit 4). Term-set mutations (`TERM_SET_MUTATION_OPS`: `AddConceptOp`, `RenameConceptOp`, `AddSynonymOp`, `RemoveSynonymOp`) append server-generated `RescoreExternalMappingOp`s; `apply()` is pure. Import replay re-scores verify-only (`IMPORT_CONFIDENCE_MISMATCH` exit 4). Serialization: `model_dump(mode="json", exclude_none=True)`. `NO_OP_DELTA` (exit 1); `MISSING_AUTO_COMMIT_PRECONDITION` (exit 2); `INVALID_WORKSPACE_ONTOLOGY`, `INVALID_PROPOSAL_STATE` (exit 4).

**Attribution Matrix**: `"delta"`: `actor="human"`, `proposer_actor=None`, `accepted_by=None`; `"construct"`: `actor="agent"|"deterministic"`, `proposer_actor=None`, `accepted_by=None`; `"proposal_accept"`: `actor="human"`, `proposer_actor="agent"|"deterministic"`, `accepted_by=_P`, `triggered_by=_P`, `triggered_by_issuance_chain=_PL`; `"revision"`: `actor="human"`, `proposer_actor=None`, `accepted_by=None`.

### 3. Server-Calculated SemVer Bumping Table
For `base_version == "0.0.0"`, initial delta advances to Genesis `1.0.0` (requires >= 1 CBC). Subsequent: `bump = max(Patch < Minor < Major)` across 23 ops: Patch (`SetDescriptionOp`, `ReviseDescriptionOp`, `RescoreExternalMappingOp`); Minor (8 additive ops `AddConceptOp`..`SetParentConceptOp`); Major (12 destructive ops [except `ReviseDescriptionOp`]; admin); Rejected (`ONT_EVO_CONTRACT_VIOLATION` exit 4: 9 BLOCK ops on deployed tables, non-optional `AddAttributeOp` on deployed `sat_*`).

### 4. Proposal Lifecycle & Attribution Integrity
1. **Creation**: In `proposals/<pid>.json`. Construct jobs set `proposer_actor: _A` from resolved mode (`"agent"`|`"deterministic"`), `proposer_principal = f"{resolved_mode}:{job_id}"`, and `triggered_by = auth_context.principal`. Envelope rejects destructive ops (`AGENT_DESTRUCTIVE_OP_FORBIDDEN` 403 exit 7, emitted as terminal SSE event).
2. **Acceptance**: `POST .../proposals/{pid}/{accept|reject|rebase}` requires `status == "PENDING"` under `.session.lock` (resolved -> 409 `PROPOSAL_ALREADY_RESOLVED` exit 6) and human actor (automated -> `AGENT_PROPOSAL_ACCEPT_FORBIDDEN` exit 7). Accept OCC: (1) `If-Match` (exit 2) -> (2) OCC (exit 5) -> (3) proposal base SHA (exit 5) -> (4) `proposal.base_version` (exit 2). Sets `actor="human"`, `accepted_by=principal`, stages `status="ACCEPTED"`, `resolved_at`, `resolved_by=accepted_by`. Emptied extensions prune via `_norm_empty` before JCS. Provenance matches `proposer_actor`/`actor` (`ONT_EVO_FORGED_PROVENANCE` exit 4). Self-acceptance (`PROPOSAL_SELF_ACCEPTANCE_FORBIDDEN` exit 7; `--allow-self-accepted-proposals` maps to `self_acceptance_override`) enforced at accept/import (`accepted_by == triggered_by` or in `triggered_by_issuance_chain`); `MutationDeltaRecord` enforces `self_acceptance_override is True` and `accepted_by == LOCAL_ADMIN_PRINCIPAL` iff self-accepting. Server derives chains from `.tokens.json` (client values rejected exit 2). Ungrounded proposals require admin (`FORBIDDEN_ADMIN_REQUIRED` exit 7). Reject stages `status="REJECTED"`, `resolved_at`, `resolved_by=principal`.
