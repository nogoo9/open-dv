# ADR-005: Non-Breaking `GraphAOntology` Model Extension with `default=None` to Preserve RFC 8785 SHA-256 Stability

## Status
Proposed

## Context
`GraphAOntology` defines the semantic contract with lineage enforced via RFC 8785 JCS SHA-256 in `opendv_core.ontology_hashing`. Certified baseline digests (`1c100409cbbe12051f7211d2d6d6838670982b9164aaf18b52f566864da90b81`) must remain bit-for-bit stable when extending models with taxonomy, attributes, synonyms, and mappings.

## Decision
We extend `CanonicalBusinessConcept` in `opendv_core.models.graph_a` strictly with optional fields defaulting to `None`, paired with canonicalization rules:

### 1. Model Extension Specification: Extension delta models (legacy base fields elided; see certified inventory below)
```python
# Minimum Python runtime: 3.11+
from typing import Annotated, Any, Literal as _L, Self
from pydantic import Field, field_validator, model_validator
from pydantic_core import PydanticCustomError as _Err
from opendv_core.models.base import StrictGraphAModel
from opendv_core.canonical import quantize_confidence, Cardinality as _C, MappingType as _M, AutomatedActor as _A, DEFAULT_DOMAIN_NAMESPACE, DEFAULT_ENTERPRISE_OWNER

def _norm_empty(d: object, opt: frozenset[str]) -> object: return {k: v for k, v in d.items() if not (k in opt and v in (None, "", [], (), {}))} if isinstance(d, dict) else d

class ExternalMapping(StrictGraphAModel):
    standard_name: str = Field(min_length=1); standard_uri: str = Field(min_length=1); mapping_type: _M = "closeMatch"; confidence: float = Field(0.0, ge=0.0, le=1.0); provenance: _L["human"] | _A; reference_pack_id: str = Field(min_length=1); reference_pack_sha256: str = Field(pattern=r"^[0-9a-f]{64}$")
    @field_validator("confidence")
    @classmethod
    def validate_confidence(cls, v: float) -> float: return quantize_confidence(v)

_ATTR_TYPE = _L["string", "integer", "decimal", "boolean", "date", "timestamp", "binary"]
_ATTR_OPT = frozenset({"definition", "example_values"})

class ConceptAttribute(StrictGraphAModel):
    attribute_name: str = Field(pattern=r"^[a-z][a-z0-9_]*$", min_length=1, max_length=63); data_type: _ATTR_TYPE = "string"; is_optional: bool = True; definition: str | None = None; example_values: list[str] | None = None
    @model_validator(mode="before")
    @classmethod
    def norm_empty(cls, d: object) -> object: return _norm_empty(d, _ATTR_OPT)

_CBC_EXT = frozenset({"parent_concept_uri", "attributes", "synonyms", "external_mappings"}); _REL_EXT = frozenset({"description", "cardinality"})
_ENUM_EXT = frozenset({"enumeration_name", "description", "code_descriptions", "enum_uri"}); _ONT_EXT = frozenset({"description", "version", "parent_sha256"}); _DFL = Field(default_factory=list)

_SYN = Annotated[str, Field(min_length=1, max_length=256)]
class CanonicalBusinessConcept(StrictGraphAModel):
    parent_concept_uri: Annotated[str | None, Field(pattern=r"^urn:opendv:concept:[a-z0-9][a-z0-9_-]*$")] = None
    attributes: list[ConceptAttribute] | None = None; synonyms: Annotated[list[_SYN] | None, Field(max_length=50)] = None; external_mappings: list[ExternalMapping] | None = None
    @model_validator(mode="before")
    @classmethod
    def norm_empty(cls, d: object) -> object: return _norm_empty(d, _CBC_EXT)
    @model_validator(mode="after")
    def validate_collections(self) -> Self:
        if self.synonyms and len(self.synonyms) != len(set(self.synonyms)): raise _Err("DUPLICATE_SYNONYM", "duplicate")
        if self.attributes and len({a.attribute_name for a in self.attributes}) != len(self.attributes): raise _Err("DUPLICATE_ATTRIBUTE_NAME", "duplicate")
        if self.external_mappings and len({(m.standard_uri, m.mapping_type) for m in self.external_mappings}) != len(self.external_mappings): raise _Err("AMBIGUOUS_EXTERNAL_MAPPING", "ambiguous")
        return self

class CanonicalRelationship(StrictGraphAModel):
    description: str | None = None; cardinality: _C | None = None
    @model_validator(mode="before")
    @classmethod
    def norm_empty(cls, d: object) -> object: return _norm_empty(d, _REL_EXT)

class ReferenceEnumeration(StrictGraphAModel):
    enumeration_name: str | None = None; description: str | None = None; code_descriptions: dict[str, str] | None = None; enum_uri: str | None = None
    @model_validator(mode="before")
    @classmethod
    def norm_empty(cls, d: object) -> object: return _norm_empty(d, _ENUM_EXT)
    @model_validator(mode="after")
    def validate_codes(self) -> Self:
        if self.code_descriptions and not set(self.code_descriptions.keys()).issubset(set(self.allowed_codes)): raise _Err("DANGLING_ENUM_CODE_DESCRIPTION", "keys must be in allowed_codes")
        return self

_H_P = r"^[0-9a-f]{64}$"; _V_P = r"^(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)\.(0|[1-9][0-9]*)$"
class GraphAOntology(StrictGraphAModel):
    description: str | None = None; version: Annotated[str | None, Field(pattern=_V_P)] = None; parent_sha256: Annotated[str | None, Field(pattern=_H_P)] = None
    @model_validator(mode="before")
    @classmethod
    def norm_empty(cls, d: object) -> object: return _norm_empty(d, _ONT_EXT)
    @model_validator(mode="after")
    def validate_version(self) -> Self:
        # ontology_version is canonical; version is legacy alias; if both present, unequal fails VERSION_CONSISTENCY_MISMATCH exit 4
        if self.version is not None and self.ontology_version and self.version != self.ontology_version: raise _Err("VERSION_CONSISTENCY_MISMATCH", "version mismatch")
        return self

# Constants in opendv_core.canonical: DEFAULT_DOMAIN_NAMESPACE = "general", DEFAULT_ENTERPRISE_OWNER = "Enterprise Architecture" (genesis-pinned); DEFAULT_EXPORT_PREFIX_IRI and cost guard policy configurable in opendv_service; modules: structural_validator (core), governance_validator (service)
# GenesisDraft in opendv_core.genesis:
_GEN_OPT = frozenset({"description", "ontology_id"})
class GenesisDraft(StrictGraphAModel):
    domain_namespace: Annotated[str, Field(pattern=r"^[a-z][a-z0-9_]*$")] = DEFAULT_DOMAIN_NAMESPACE; enterprise_owner: str = DEFAULT_ENTERPRISE_OWNER; ontology_version: str = "0.0.0"; ontology_id: str | None = None; description: str | None = None; canonical_business_concepts: list[CanonicalBusinessConcept] = _DFL; canonical_relationships: list[CanonicalRelationship] = _DFL; reference_enumerations: list[ReferenceEnumeration] = _DFL; standards_references: list[str] = _DFL; decision_refs: list[str] = _DFL
    @model_validator(mode="before")
    @classmethod
    def norm_empty(cls, d: object) -> object: return _norm_empty(d, _GEN_OPT)
```

### 2. Normative Model Field Inventory & Hash Stability Rules
`compute_ontology_sha256(ontology: GraphAOntology | GenesisDraft) -> str` in `opendv_core.ontology_hashing`:
1. `raw = ontology.model_dump(mode="json", exclude_none=True)`.
2. `canonical = canonicalize_graph_a_dict(raw)`: traverses nested structures, applying `_norm_empty` per level: root (`_ONT_EXT`), CBC (`_CBC_EXT`), attributes (`_ATTR_OPT`), rels (`_REL_EXT`), enums (`_ENUM_EXT`), pruning empty/None extensions so emptied extensions hash identically to never-set ones. Steps 1 & 3 match legacy.
3. Returns `hashlib.sha256(rfc8785.dumps(canonical)).hexdigest()`. Stored bytes of `versions/vX/ontology.json` equal `rfc8785.dumps(canonical)` matching `raw_byte_sha256 == target_sha256` bit-for-bit in commit and recovery.

`StrictGraphAModel` (`extra="forbid"`, `strict=True`, `validate_assignment=True`) preserves baseline behavior. `schemas/v1/baseline-digests.json` anchors certified digests (`pe`: `1c100409cbbe12051f7211d2d6d6838670982b9164aaf18b52f566864da90b81`; `s2`, `s3`, `s9`, `issue_40`, `uf2`). CI asserts byte-identity against frozen legacy copy. Schema diff verifies extension sets absent from `main`. Tests assert `canonicalize_graph_a_dict(legacy) == legacy`.

- **Field Inventory & Defaults**: Extensions in `_CBC_EXT`, `_ATTR_OPT`, `_REL_EXT`, `_ENUM_EXT`, `_ONT_EXT`. `CanonicalBusinessConcept.description` (`str | None = None`) is an existing base field; `clear=True` resets to `None`. Non-SemVer workspace versions fail `INVALID_WORKSPACE_ONTOLOGY` (exit 4). Legacy concepts failing `_CU` are read-only baseline references; addressing in deltas fails `SYNTAX_INVALID_ARGUMENT` (exit 2). Defaults (`data_type="string"`, `is_optional=True`; `mapping_type="closeMatch"`) frozen in v1, serializing only when parent exists.

**Stability Invariants & Lifecycle**:
1. **Genesis**: `GenesisDraft` (in `opendv_core.genesis`, vector `1916a5c6d501015984b887fd76609b225b72d5d393e5813d8df210b92ab3b4c9`). Advances to 1.0.0 setting `parent_sha256 = compute_ontology_sha256(genesis_template(params))`, requiring >= 1 CBC (`GENESIS_REQUIRES_CONCEPT` exit 4; deleting last CBC fails `ONTOLOGY_REQUIRES_CONCEPT`).
2. **Commit Normalization**: Sets `ontology_version = version = target_version`, `parent_sha256 = base_sha256`. `NO_OP_DELTA` (exit 1) ignores lineage. Emptied extensions prune via `_norm_empty` before JCS. Seeding stores raw file (`seed_source_file_sha256`); `ontology.json` is RFC 8785 JCS (`target_sha256 == seed_source_sha256 == compute_ontology_sha256(model)`) with `grandfathered_concept_uris` in `meta.json`. Reserved-token scans are unwaivable on seed roots (`ONT_EVO_GROUNDING_VIOLATION` exit 4). Promotion requires edits beyond seed root (`NO_OP_DELTA` exit 1).
3. **Reference Packs**: `reference_pack_id` and `reference_pack_sha256` required on `ExternalMapping` (missing payload `SYNTAX_INVALID_ARGUMENT` exit 2). Append-only registry (`<pack_id>-<sha256_8>.json`). Ungrounded URI/label mismatch fails `ONT_EVO_GROUNDING_VIOLATION` (exit 4); unregistered pack fails `UNKNOWN_REFERENCE_PACK`/`IMPORT_UNKNOWN_REFERENCE_PACK` (exit 4). `RepinExternalMappingOp` (Major, admin, PERMIT on deployed) repins to registered packs, re-running Server Grounding against target pack BM25.
4. **Float Encoding**: `opendv_core.canonical.quantize_confidence(v)` (`float(Decimal(str(v)).quantize(Decimal("0.0001"), rounding=ROUND_HALF_EVEN)) + 0.0`).
5. **RDF Alignment**: `exactMatch` -> `skos:exactMatch`, `closeMatch` -> `skos:closeMatch`, `broadMatch` -> `skos:broadMatch`, `subClassOf` -> `rdfs:subClassOf`.

## Consequences & Compliance
Zero hash regression; strict typing (`StrictGraphAModel`). Baseline tests verify bit-for-bit matches across all 6 certified fixtures (`pe`, `s2`, `s3`, `s9`, `issue_40`, `uf2`). For identical lineage fields, an ontology whose extensions are emptied hashes identically to one where they were never set.
