# ADR-003: FIBO Curated Vendored Subset (`scripts/vendor_fibo.py`, 6 Modules: FND, BE, FBC, SEC, LOAN, IND)

## Status
Proposed

## Context
FIBO provides standardized financial semantics. Bundling all modules inflates repo size; downloading dynamically risks network failure and breaks air-gapped execution.

## Decision
We vendor a curated, compact subset of FIBO into the repository:

### 1. Vendor Script (`scripts/vendor_fibo.py`)
- Pinned in `vendor/fibo.lock.json` to `master_2024Q4` (`69dbbe7a6a4e32049ba3f3988b48877bc954f061`) with committed archive SHA-256; supports `--check` for drift detection and `--dry-run` for preview without modifying disk.

### 2. 6 Core Modules
Scope: `FND` (Foundations), `BE` (Business Entities), `FBC` (Financial Business/Commerce), `SEC` (Securities), `LOAN` (Loans), `IND` (Indicators/Indices).

### 3. Committed Core Pack (`fibo-core-<sha256_8>.json` via `reference/registry.json`)
- Compiled via `rdflib` into `opendv_sources.reference`. JCS bytes ensure `raw_byte_sha256 == sha256(JCS(pack))`. Sorted deterministically: concepts by `concept_uri`, parents/synonyms by NFC code point. MIT in `vendor/NOTICE`. `.gitattributes` marks packs/vectors as `-text` (binary); CI asserts zero `\r`.
- **Parent Hierarchy & Grounding Closure Rule**: `vendor_fibo.py` filters parents outside 6 modules; pack stores URIs in `parent_concept_uris` resolving in pack. Closure `subClassOf` mappings are verified structurally, exempt from BM25, confidence 1.0; `subClassOf` never satisfies positive grounding alone. Removing (`RemoveExternalMappingOp`) or repinning (`RepinExternalMappingOp`) an anchor re-checks closure: dependent closure `subClassOf` mappings must cascade in same delta (else `ONT_EVO_GROUNDING_VIOLATION` exit 4); anchor write conflict keys include closure dependents.
- **Versioned Pack Storage & Append-Only Registry**: Registry binds `(pack_id, pack_sha256)`; `ReferenceOntologyAdapter` verifies raw bytes (`REFERENCE_PACK_INTEGRITY_FAILURE` 500 exit 1). `RepinExternalMappingOp` (Major, admin, PERMIT on deployed) repins to registered packs, re-running Server Grounding (< 0.65 requires waiver per ADR-007 §2, else `ONT_EVO_LOW_CONFIDENCE_GROUNDING` 422 exit 4; closure `subClassOf` 1.0).

## Consequences & Compliance
Offline execution; ~4 MB pack, <18 MB RAM, <70ms load; extensible SPI. Tests verify `fibo-core-<sha256_8>.json` matches RFC 8785 JCS digest across OS runners, and 100% of `parent_concept_uris` resolve in pack.
