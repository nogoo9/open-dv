# ADR-001: Autonomous End-to-End Delivery Lifecycle (Review Only Final PR)

## Status
Proposed

## Context
The Studio spans 7 phases (0–6). Traditional approval gates introduce latency; autonomous execution maximizes velocity while maintaining quality.

## Decision
Delivery across Phases 0 through 6e executes autonomously end-to-end without intermediate approval gates:

1. **No Intermediate Human Approval Gates**: Subagents execute autonomously across Phases 0–6 (except Phase 4A contract-freeze checkpoint); Opus critique (0 CRITICAL, 0 MAJOR) and CI gates apply per phase.
2. **Review Only Final PR**: Human review concentrated on final PR from `dev/ontology-studio` to `main`.
3. **Safety & Quality**: 100% green CI; human checkpoint on Phase 4A contract freeze; emergency escalation halts only affected sub-track. CODEOWNERS enforces human approval on hash and governance critical paths (`opendv_core.ontology_hashing`, `opendv_core.canonical`, `governance_validator`, `schemas/v1/baseline-digests.json`).

## Consequences & Compliance
High velocity; human review on final PR. Branch protection requires 100% passing CI and Opus critique reports. Release script (`scripts/open_final_pr.py`) creates final PR to `main` (`draft: true`).
