# Open-DV Ontology Construction Studio: Design Handoff (HANDOFF.md)
**Status:** Proposed Baseline (Under M1 Review) | **Branch:** `dev/ontology-studio` | **Ref:** `master-plan.md`, `research.md`, ADR-001..016

## 1. Executive Summary & Binding Matrix
The Studio ingests documents, grounds in FIBO, resolves ambiguities, and generates Data Vault 2.0 Graph A ontologies. Tracks bind to ADR-001..016 on gate pass. Layout (`/ontology`): nav, drawer, status, panels (Sources, Clarifications, Explorer, Quality, Export).

## 2. Interface Stability Contracts & Invariance Guarantees

### 2.1 Contract 1: Core Models & Hash Stability (ADR-005)
Extensions in `opendv_core.models.graph_a` default `None`. `CanonicalBusinessConcept` validates collections (synonyms 1..256 max 50; unique `attribute_name`s, unique mappings, parent URI `_CU`). `description` defaults `None`; `clear=True` resets to `None`. Child defaults (`data_type="string"`, `is_optional=True`) frozen in v1. `compute_ontology_sha256` runs `jcs(canonicalize_graph_a_dict(ontology))` on `model_dump(mode="json", exclude_none=True)` with recursive `_norm_empty` (pruning empty/None keys so emptied extensions hash identically to never-set ones), preserving digest `1c100409cbbe12051f7211d2d6d6838670982b9164aaf18b52f566864da90b81` under `StrictGraphAModel`. Greenfield: `GenesisDraft` (`1916a5c6d501015984b887fd76609b225b72d5d393e5813d8df210b92ab3b4c9`). Non-SemVer workspace versions fail `INVALID_WORKSPACE_ONTOLOGY` (exit 4). Seed records `grandfathered_concept_uris: list[_CU]` in `meta.json`: `target_sha256 == seed_source_sha256 == compute_ontology_sha256(model)`.

### 2.2 Contract 2: `OntologyDelta` Operations & Request Envelopes (ADR-006)
9 client additive ops (`ClientDeltaOp`) + 1 server-only `RescoreExternalMappingOp` (10 total additive, 13 destructive `StewardRevisionRequest`, admin exit 7). Delta ops type URIs with `_CU`/`_RU` (`SYNTAX_INVALID_ARGUMENT` exit 2 at Step 4). `ReviseDescriptionOp` requires `clear: bool = False` or `new_description: str | None = None`. Term-set mutations append server-generated `RescoreExternalMappingOp`s; `apply()` is pure. Import replay executes pure `apply()` and re-scores verify-only (closure `subClassOf` 1.0; mismatch `IMPORT_CONFIDENCE_MISMATCH` exit 4). `_norm_desc_target` drops `concept_uri` (`VALIDATION_AMBIGUOUS_TARGET` exit 2). Cascades: code_descriptions and attrs/syns/mappings (`CONCEPT_STILL_REFERENCED` exit 4). Direct `/delta` requires human. Genesis 0.0.0->1.0.0 requires >= 1 CBC (`GENESIS_REQUIRES_CONCEPT` exit 4). SemVer: desc/rescore -> Patch; Additive -> Minor; 12 destructive ops -> Major (admin). Auto-commit sets `author=f"{resolved_mode}:{job_id}"`, `actor=resolved_mode`, `triggered_by=principal`. `EvidenceGroundingApproval.approved_by` server-bound (`ONT_EVO_FORGED_PROVENANCE` exit 4). `ProposalRecord` sets proposer/author metadata, recording `accepted_delta_id: _U` and `accepted_target_version: _V` when ACCEPTED. Accept OCC: (1) `If-Match` (exit 2) -> (2) OCC (exit 5) -> (3) proposal `base_sha256` (exit 5) -> (4) `active_version` (exit 2). Self-acceptance (`PROPOSAL_SELF_ACCEPTANCE_FORBIDDEN` exit 7; `--allow-self-accepted-proposals` maps to `self_acceptance_override`) requires `LOCAL_ADMIN_PRINCIPAL`. Rebase evaluates 23-op conflict keys (exit 5); cycle fails `HIERARCHICAL_CYCLE_DETECTED` (exit 4).

### 2.3 Contract 3: ONT-EVO Governance Rules (ADR-007)
`opendv_core.ontology.structural_validator` checks structural invariants (URI grammar, DAG acyclicity, 1:1 Hub bijection, collisions, reserved tokens `PROVISIONAL_URI_PATTERN = r"(?i)urn:opendv:provisional:"`); `opendv_service.ontology.governance_validator` checks business invariants (reference packs, BM25 Server Grounding, `EvidenceRef` CAS snippets, provenance; closure `subClassOf` exempt). Committed versions immutable; deployed matrix covers 23 ops: 9 BLOCK destructive + conditional BLOCK for non-optional `AddAttributeOp` on deployed sat_*; 14 PERMIT (4 destructive + 10 additive; `ONT_EVO_CONTRACT_VIOLATION` exit 4). Promotion acquires `graph_a.lock` -> `.session.lock`, validates `OPENDV_WORKSPACE_ROOTS` (`INVALID_WORKSPACE_PATH` exit 2; remote rejects `server_path` `REMOTE_SERVER_PATH_FORBIDDEN` exit 2), requires `--rationale <t>` (missing exit 2, blank `PROMOTION_RATIONALE_REQUIRED` exit 1), re-asserts ONT-EVO-002 on touched concepts: >= 1 non-subClassOf mapping in registered pack >= 0.65 OR admin waiver `low_confidence_grounding_waiver=True` in `meta.json` (imported requires `acknowledged_attribution=True`) OR verified `evidence_grounding` (zero fails `ONT_EVO_UNGROUNDED_CONCEPT` exit 4; grandfathered seed concepts in `grandfathered_concept_uris` exempt while untouched), writing head under `graph_a.lock`. Greenfield promote: `"0"*64` accepted iff genesis lineage without seed. Symmetric BM25 divides by `max(Score(C, C.name), Score(Q, Q))`. `construct(auto_commit=True)` requires `If-Match` (exit 2) and re-verifies `head_sha256` at commit (exit 5). Precedence: syntax exit 2 wins; else location-order uniqueness exit 4.

### 2.4 Contract 4: Canonical CAS Session Storage Layout (ADR-009 / ADR-014 / ADR-016)
Layout `<studio_root>/<session_id>/` (0700/DACL): `.session.lock`, `.session_secret` (0600), `session.json`, `taint_index.json`, `audit.jsonl` (90d), `feedback.jsonl`, `inputs/`, `evidence/`, `clarifications/`, `proposals/`, `versions/vX/`, `jobs/`. Unpinned jobs snapshot `head_sha256` under `.session.lock` at init. Lock order: `.local_token.lock` -> Job Lease (`.job_<jid>.lock`) -> `.journal_<job_id>.lock` -> Workspace Lock (`graph_a.lock`) -> Session Lock (`.session.lock`). `VersionMetaRecord` records mode (`meta.json` immutable on import; `ImportProvenanceRecord` in `import_provenance.json`), `requested_mode`, `construction_mode`, matcher `bm25_fibo_v1` v1.0.0 (`(matcher_sha256, reference_pack_sha256)`). CAS GC purges unreferenced blobs; reachability covers manifests, `evidence/`, PENDING proposals (`SOURCE_REFERENCED_BY_PENDING_PROPOSAL` exit 4), and `source_sha256` in committed versions (`SOURCE_REFERENCED_BY_COMMITTED_VERSION` exit 4). `.odvstudio.zip` limits (250 MB, 500 entries, 100:1; `ARCHIVE_SECURITY_VIOLATION` exit 4). Tainted export requires `--acknowledge-confidential-source-export --export-rationale <t>` (unack exit 4; missing exit 1). Bundled overrides, low confidence, or evidence grounding require admin `--acknowledge-unverified-import-attribution --acknowledgement-rationale <t>` (unack override `IMPORT_SELF_ACCEPTANCE_UNACKNOWLEDGED`, unack grounding `IMPORT_GROUNDING_VIOLATION` exit 4; missing `IMPORT_GROUNDING_RATIONALE_REQUIRED` exit 1; zero mappings/evidence fails `ONT_EVO_UNGROUNDED_CONCEPT` exit 4). Imported seed roots exempt only when lineage `grandfathered_concept_uris` match verified seed root. Warnings reject `HISTORICAL_CONTRACT_WARNING_UNACKNOWLEDGED` (exit 4; waivable via rationale, missing `HISTORICAL_CONTRACT_RATIONALE_REQUIRED` exit 1). Tainted entities scrub to `"[REDACTED_ODV_CONFIDENTIAL_SOURCE]"` via HMAC.

### 2.5 Contract 5: REST & SSE Platform API (`/api/v1/ontology/studio`)
Auth via `X-OpenDV-Token` or cookie (401 exit 7). Loopback `POST /init` requires `X-OpenDV-Workbench: 1`, verifies loopback peer (`127.0.0.1`/`::1`), creates `.local_token` (0600; 409 exit 6). Remote disables `/init` and loopback privileges (`LOOPBACK_PRIVILEGE_DISABLED_IN_REMOTE_MODE` 403 exit 7); local binds to loopback (`127.0.0.1`/`::1`). Host allowlist `{"localhost", "127.0.0.1", "::1"}` parses authority per RFC 3986. Async pipelines accept `[--stream]` and `[--wait]`, returning 202; streaming CLI monitors SSE stream, exiting with code from terminal `error_code` (0 on success).

### 2.6 Contract 6: Dual CLI Parity Contract (`schemas/v1/cli-spec.json`)
Both CLIs enforce Step 0 syntax (exit 2), executing pipeline per ADR-007 §3: token resolution (401 exit 7), preconditions (exit 2), and RBAC per `schemas/v1/cli-spec.json` (`viewer` read-only; `editor` additions, construct, proposals; `admin` revisions, waivers, override, `promote`, tokens; automated denied direct mutations). Flags: `client_file_upload` (`opendvctl` streams, `LocalExecutor` local); `client_file_download` (`export --out`); `server_path`. `--file` accepts operations list or full request with optional `--rationale <t>`. Remote `opendvctl` rejects `server_path` (`REMOTE_SERVER_PATH_FORBIDDEN` exit 2). Closed error codes per ADR-012 §4 (including `VERSION_CONSISTENCY_MISMATCH` exit 4; `check_error_codes.py` validates). Commands accept `<id>` / `--session <id>`, derive exit codes (0..7), emitting JCS; `promote` requires `--workspace-sha256 <s>`, `--head-sha256 <s>`, `--rationale <t>`. Strict TypeScript in Bun CI.
