# ADR-012: Dual CLI Parity Architecture (`opendv` LocalExecutor and `opendvctl` Bun Client)

## Status
Proposed

## Context
Open-DV provides Python (`opendv`) and TypeScript/Bun (`opendvctl`) CLIs with complete command, flag, exit code, and payload parity.

## Decision
We enforce a Dual CLI Parity Architecture governed by `schemas/v1/cli-spec.json`:

### 1. Canonical Command Tree & REST Endpoint Mapping
All Studio REST endpoints are rooted at `/api/v1/ontology/studio` (short paths map to this base):
- `studio init` <-> `POST /init` (creates `.local_token` [0600]; 409 exit 6; insecure perms exit 1); `studio open <id> [--role <r>]` <-> `POST .../launch-token`.
- `studio token {issue [--role <r>] [--principal <p>]|list|revoke <id>}` <-> `/auth/tokens` (admin; human only; `LOCAL_ADMIN_PRINCIPAL` reserved 409 exit 6).
- `session {create [--from-workspace <p>] [--domain-namespace <ns>] [--enterprise-owner <o>] [--ontology-id <id>] [--description <d>]|list|show <id>|delete <id>|prune [--before <ts>]|clone <id> [--session-label <l>]}` <-> `/sessions` (admin delete/prune).
- `session gc [<id>] [--all]` <-> `POST .../sessions/{id}/gc` (or `POST .../sessions/gc` with `--all`; admin).
- `session export <id> --out <p> [--acknowledge-confidential-source-export --export-rationale <t>]` <-> `POST .../bundle`; `session import <p> [--acknowledge-unverified-import-attribution --acknowledgement-rationale <t>] [--acknowledge-historical-contract-warning --historical-contract-rationale <t>]` <-> `POST .../import` (admin; unack exit 4; missing rationale exit 1).
- `source {add <p> [--do-not-send-to-agent]|list|remove <source_id>|set-privacy <source_id> --clear}` <-> `/sessions/{id}/sources` (cited removal exit 4; clear privacy requires admin).
- `{parse|clarify} <id> [--stream] [--wait]` <-> `.../{parse|clarify}`; `clarification {list|answer --file <f>}` <-> `.../clarifications`, `.../answers`.
- `construct <id> [--base-version <v> --base-sha256 <s>] [--mode <m>] [--auto-commit] [--stream] [--wait]` <-> `POST .../construct` (unpinned auto-commit fails exit 2).
- `proposal {list|show|reject|accept --base-sha256 <s> [--low-confidence-waiver --grounding-rationale <t> --ungrounded-concept <uri>...] [--evidence-grounding-file <f>] [--allow-self-accepted-proposals]|rebase [--base-sha256 <s>]} <id> [<pid>]` <-> `.../proposals` (`--allow-self-accepted-proposals` maps to `self_acceptance_override`; waiver/override admin exit 7; conflict exit 5).
- `{delta|revision} apply <id> --file <f> [--rationale <t>] --base-version <v> --base-sha256 <s> [--low-confidence-waiver --grounding-rationale <t> --ungrounded-concept <uri>...] [--evidence-grounding-file <f>]` <-> `POST .../{delta|revision}` (`--file` accepts `operations` list or full request; file/flag mismatch fails `SYNTAX_INVALID_ARGUMENT` exit 2; `--rationale` overrides; revision admin; waiver admin exit 7).
- `version {list|show} <id> [<v>]` <-> `.../versions`; `reference list` <-> `/references`; `diff <id> [--from <v1>] [--to <v2>]` <-> `GET .../diff`.
- `quality <id> [--version <v>]` / `feedback <id> --rating <r> [--comment <t>]` <-> `.../quality`, `.../feedback`; `export <id> --export-format <fmt> [--version <v>] [--out <p>]` <-> `GET .../export`.
- `promote <id> [--workspace <p>] --workspace-sha256 <s> --head-sha256 <s> --rationale <t> [--acknowledge-historical-contract-warning --historical-contract-rationale <t>]` <-> `POST .../promote` (`OPENDV_WORKSPACE_ROOTS` exit 2; greenfield `"0"*64`; missing required flags exit 2; blank/empty rationale `PROMOTION_RATIONALE_REQUIRED` exit 1; unack exit 4; missing `HISTORICAL_CONTRACT_RATIONALE_REQUIRED` exit 1); `workspace status` <-> `GET /workspace/status`.
- `job {list|show <jid>|cancel <jid>|events <jid> [--last-event-id <n>]}` <-> `/sessions/{id}/jobs`.

**Session Targeting & Contract Authority**: RBAC in `schemas/v1/cli-spec.json` and error codes in `schemas/v1/error-codes.json` bind both CLIs and REST:
- `viewer`: Read-only (`session`, `version`, `reference`, `diff`, `quality`, `job`, `source`, `clarification`, `proposal`, `workspace status`, `export`).
- `editor`: Viewer plus `studio open`, `session create`, `source add/remove`, `parse/clarify`, `clarification answer`, `construct`, `delta apply`, `proposal accept/reject/rebase` (non-waiver), `feedback`, `job cancel [own]`. Automated denied mutations/construct (403 exit 7).
- `admin` (human only): Editor plus `promote`, `session delete/prune/gc/export/import/clone`, `source set-privacy --clear`, `revision apply`, waivers (`low_confidence_grounding_waiver=True`), self-acceptance override, Major bumps, tokens, `studio open --role admin`, `job cancel [any]`. Automated denied admin ops (`AGENT_ADMIN_OP_FORBIDDEN` exit 7).
Targeting: `<id>` / `--session <id>`. Flags: `client_file_upload` (`source add`, `session import`, `apply --file`, `clarification answer`, `--evidence-grounding-file`); `client_file_download` (`export --out`); `server_path` (remote rejects `REMOTE_SERVER_PATH_FORBIDDEN` exit 2). Required flags (exit 2): `--base-sha256`/`--base-version` on deltas/revisions; `--base-sha256` on proposal accept; `--workspace-sha256`/`--head-sha256`/`--rationale` on promote; unpinned auto-commit fails `MISSING_AUTO_COMMIT_PRECONDITION` exit 2; waiver requires `--low-confidence-waiver` (or `--accept-ungrounded`) with `--grounding-rationale` and `--ungrounded-concept` (missing exit 2; <10 chars fails `INVALID_GROUNDING_WAIVER` exit 4; unack rationales fail `*_RATIONALE_REQUIRED` exit 1). Conflicts -> 412 exit 5.

### 2. Execution Paradigms, Security Context & Parity Pipeline
Both `opendv` (`LocalExecutor`) and `opendvctl` (REST/SSE via `OPENDV_API_URL`) execute identical pipeline governed authoritatively by ADR-007 §3:
1. **AuthN & Loopback Equivalence**: Precedence: (1) `OPENDV_TOKEN`; (2) `OPENDV_LOCAL_TOKEN_PATH`; (3) `<studio_root>/.local_token` (0600; `human:local_admin`). Unauthenticated -> 401 exit 7 (`studio init` exempt; reserved principal fails `PRINCIPAL_RESERVED` 409 exit 6; insecure perms fail exit 1). `LocalExecutor` resolves principal identically (automated fail 403 exit 7). `opendvctl` sends `self_acceptance_override: bool` (gated by loopback, `LOCAL_ADMIN_PRINCIPAL`, `OPENDV_ALLOW_SELF_ACCEPTED_PROPOSALS`; `LocalExecutor` applies equivalent gate). Remote disables `/init` and loopback (`LOOPBACK_PRIVILEGE_DISABLED_IN_REMOTE_MODE` 403 exit 7).
2. **Canonical Precedence & Flag Parity**: Both CLIs enforce Step 0 syntax validation (exit 2): missing required flags fail locally before network dispatch. Valid requests execute server pipeline per ADR-007 §3. Tests assert missing flags exit 2 and unauthorized mutations fail Step 3 RBAC (exit 7).
3. **Exit Codes**: Exact matches in `schemas/v1/error-codes.json` govern exit codes (0..7).

### 3. Bit-for-Bit Parity Verification & Output Normalization
`--output-format json` emits RFC 8785 canonical JSON in both CLIs. Parity tests mask dynamic fields, verifying identical trees, flags, payload keys, exit codes, and byte-for-byte serialization.

### 4. Normative Exit Code Specification
Authoritative in `schemas/v1/error-codes.json` (Track 4A). **Precedence**: (1) Exact literal over wildcards; (2) Not-found (`SESSION_NOT_FOUND`, `VERSION_NOT_FOUND`, `PROPOSAL_NOT_FOUND`, `SOURCE_NOT_FOUND`, `JOB_NOT_FOUND`) maps to 404 exit 3; (3) Domain missing entities (`REFERENCED_CONCEPT_NOT_FOUND`, `PARENT_NOT_FOUND`, `ATTRIBUTE_NOT_FOUND`, `MAPPING_NOT_FOUND`, `RELATIONSHIP_NOT_FOUND`, `ENUM_CODE_NOT_FOUND`) map to 422 exit 4; (4) OCC to 412 exit 5; (5) AuthN/RBAC to 401/403 exit 7; (6) `scripts/check_error_codes.py` validates against `error-codes.json`.
- `0` (Success): Completed successfully (HTTP 200, 201, 202).
- `1` (System & Capability / HTTP 400/422/500/501/503): `NO_OP_DELTA`, `MATCHER_UNIDATA_VERSION_MISMATCH`, `OCR_UNAVAILABLE`, `OFFICE_CONVERSION_UNAVAILABLE`, `AGENT_UNAVAILABLE`, `JOB_ABANDONED_SERVER_CRASH`, `VERSION_COMMIT_IO_FAILURE`, `INSECURE_STUDIO_ROOT_PERMISSIONS`, `REFERENCE_PACK_INTEGRITY_FAILURE`, `CONFLICTING_WORKSPACE_SEED_PARAMS`, `HISTORICAL_CONTRACT_RATIONALE_REQUIRED`, `PROMOTION_RATIONALE_REQUIRED`, `*_RATIONALE_REQUIRED`, `CORRUPT_SESSION_RECORD`.
- `2` (Syntax/Precondition / HTTP 400): Missing required flags (`--base-sha256`, `--base-version`, `--workspace-sha256`, `--head-sha256`), syntax (`SYNTAX_INVALID_ARGUMENT`, `VALIDATION_AMBIGUOUS_TARGET`, `INVALID_EVIDENCE_OFFSETS`), preconditions (`MISSING_PRECONDITION_HEADER`, `MISSING_AUTO_COMMIT_PRECONDITION`, `PRECONDITION_BASE_SHA_MISMATCH`, `INVALID_PRECONDITION_HEADER`, `INVALID_SESSION_IDENTIFIER`, `INVALID_WORKSPACE_PATH`, `REMOTE_SERVER_PATH_FORBIDDEN`).
- `3` (Resource Not Found / HTTP 404): `SESSION_NOT_FOUND`, `VERSION_NOT_FOUND`, `PROPOSAL_NOT_FOUND`, `SOURCE_NOT_FOUND`, `JOB_NOT_FOUND`.
- `4` (Domain & Referential / HTTP 422): `ONT_EVO_*` (except OCC [5]), `IMPORT_*` (except rationale [1]), `ONT_EVO_ENVELOPE_VIOLATION`, `AUTOMATED_ATTRIBUTION_INVALID`, `DUPLICATE_RELATIONSHIP_URI`, `CONCEPT_STILL_REFERENCED`, `REFERENCED_CONCEPT_NOT_FOUND`, `PARENT_NOT_FOUND`, `ATTRIBUTE_NOT_FOUND`, `MAPPING_NOT_FOUND`, `RELATIONSHIP_NOT_FOUND`, `ENUM_CODE_NOT_FOUND`, `DUPLICATE_*`, `DANGLING_*`, `INVALID_GROUNDING_WAIVER`, `INVALID_EVIDENCE_GROUNDING`, `INVALID_PROPOSAL_STATE`, `HISTORICAL_CONTRACT_WARNING_UNACKNOWLEDGED`, `CONFIDENTIAL_SOURCE_EXPORT_UNACKNOWLEDGED`, `ARCHIVE_SECURITY_VIOLATION`, `AMBIGUOUS_EXTERNAL_MAPPING`, `HUB_BIJECTION_VIOLATION`, `PHYSICAL_TABLE_NAME_COLLISION`, `INVALID_PHYSICAL_TABLE_NAME`, `UNDEFINED_PHYSICAL_TABLE_MAPPING`, `REDACTED_PLACEHOLDER_LEAK`, `DESCRIPTION_ALREADY_EXISTS`, `PARENT_ALREADY_EXISTS`, `VERSION_CONSISTENCY_MISMATCH`, `INVALID_WORKSPACE_ONTOLOGY`, `AGENT_UNRESOLVED_PSEUDONYM`, `EVIDENCE_OFFSET_OUT_OF_RANGE`, `ONTOLOGY_REQUIRES_CONCEPT`, `GENESIS_REQUIRES_CONCEPT`, `CANNOT_DELETE_PROMOTED_SESSION`, `CANNOT_PRUNE_PROMOTED_SESSION`, `SOURCE_REFERENCED_BY_*`, `HIERARCHICAL_CYCLE_DETECTED`, `UNKNOWN_REFERENCE_PACK`.
- `5` (OCC Conflict / HTTP 412): `ONT_EVO_CONCURRENT_MODIFICATION`, `LINEAGE_ROOT_MISMATCH`.
- `6` (Lock/In Progress / HTTP 409): `LOCK_TIMEOUT`, `JOB_COMMIT_IN_PROGRESS`, `PROPOSAL_ALREADY_RESOLVED`, `STUDIO_ALREADY_INITIALIZED`, `PRINCIPAL_RESERVED`, `PRINCIPAL_ALREADY_EXISTS`.
- `7` (Auth/RBAC / HTTP 401/403): `UNAUTHENTICATED`, `FORBIDDEN_ADMIN_REQUIRED`, `CSRF_ORIGIN_MISMATCH`, `AGENT_OPERATION_FORBIDDEN`, `SERVER_OPERATION_FORBIDDEN`, `AGENT_PROPOSAL_ACCEPT_FORBIDDEN`, `PROPOSAL_SELF_ACCEPTANCE_FORBIDDEN`, `AGENT_METADATA_OVERWRITE_FORBIDDEN`, `AGENT_ADMIN_OP_FORBIDDEN`, `AGENT_DESTRUCTIVE_OP_FORBIDDEN`, `LOOPBACK_PRIVILEGE_DISABLED_IN_REMOTE_MODE` (`IMPORT_AGENT_DESTRUCTIVE_OP_FORBIDDEN` exit 4).

## Consequences & Compliance
Seamless operator experience; drift blocked via `schemas/v1/cli-spec.json`. Tests assert canonical output equality on masked payloads across all waiver paths.
