# ADR-014: Studio Session Bundle Portability (`.odvstudio.zip` Export/Import/Clone)

## Status
Proposed

## Context
Collaborative ontology engineering requires sharing, archiving, and branching modeling sessions across environments via `.odvstudio.zip`. Importing external archives presents risks: path traversal, excessive uncompressed size, ungrounded provisional URIs, fake lineage, or destructive schema mutations in session history.

## Decision
We implement **Secure Studio Session Bundle Portability (`.odvstudio.zip`) with Full Import Re-validation**:

### 1. Bundle Specification
A `.odvstudio.zip` archive contains: `manifest.json` (`odvstudio_v1`, checksums), `session.json`, `inputs/` (`manifest.json`, CAS blobs), `taint_index.json`, `evidence/`, `clarifications/`, `proposals/`, `versions/vX/` (`ontology.yaml`, `ontology.json`, `delta.json`, `meta.json`), and `feedback.jsonl` (`.session_secret`, `.session.lock`, `audit.jsonl`, `.tokens.json`, `.local_token.lock`, `*.lock` excluded). Export via `POST /sessions/{id}/bundle` or `session export <id> --out <p>` requires `admin`; tainted sessions (`do_not_send_to_agent=True`) require `--acknowledge-confidential-source-export --export-rationale <t>` (unack `CONFIDENTIAL_SOURCE_EXPORT_UNACKNOWLEDGED` 422 exit 4; missing `EXPORT_RATIONALE_REQUIRED` 400 exit 1; logged to `audit.jsonl`).

### 2. Multi-Layer Import Validation Pipeline
When importing an archive via CLI or `POST /sessions/import`:
1. **Streaming Archive Boundary Checks**: Limits: max 250 MB uncompressed, 500 entries, 100:1 ratio on entries > 1 MB. Directory entries (single trailing '/' and `is_dir()`) are skipped safely. A file entry is rejected (`ARCHIVE_SECURITY_VIOLATION` 422 exit 4) if it starts with '/' or '\', contains '\', has a drive prefix (`^[A-Za-z]:`), contains ':' anywhere, has any path segment equal to '..' or '.', has an internal empty segment, is a symlink, or duplicates an existing entry under NFC and casefold normalization.
2. **Corruption Verification**: Verify SHA-256 digests against `manifest.json`.
3. **Normative Model, Delta Replay & Lineage Re-validation**:
   - **Structural Validation on Every Version**: Passes `opendv_core.ontology.structural_validator`: `StrictGraphAModel`, DAG acyclicity, Hub bijection, table collisions, referential integrity. Delta replay enforces concept-URI grammar across all delta ops (failing `SYNTAX_INVALID_ARGUMENT` 400 exit 2). Legacy URIs grandfathered strictly in seed root `grandfathered_concept_uris` (verified against `seed_source_sha256`; seeded legacy concepts are read-only baseline references); reserved-token scans (provisional, pseudonym, placeholder) are unwaivable.
   - **Pseudonym & Provisional Scanning**: Reserved-token scans across ALL string fields on import use ADR-007 §2 patterns: provisional URIs (`IMPORT_PROVISIONAL_URI_FORBIDDEN`, 422 exit 4), pseudonyms, and placeholders (`ONT_EVO_PSEUDONYM_LEAK`, `REDACTED_PLACEHOLDER_LEAK`, 422 exit 4).
   - **Unified External Grounding Rule**: Every external mapping across every version must resolve in the pack identified by pinned `reference_pack_sha256` (`raw_byte_sha256 == sha256(JCS(pack))`) registered in `ReferenceOntologyAdapter` (missing pack -> `IMPORT_UNKNOWN_REFERENCE_PACK` [422, exit 4]; ungrounded URI -> `ONT_EVO_GROUNDING_VIOLATION`).
      - **Delta Replay, Lineage & Grounding Re-validation**: Committed `delta.json` stores server-normalized ops. Replay verifies: seeds `target_sha256 == seed_source_sha256 == compute_ontology_sha256(model)` with `grandfathered_concept_uris` verified against seed root; mutations `compute_ontology_sha256(apply(v[n-1], delta[n])) == meta.target_sha256 == raw_byte_sha256(versions/vN/ontology.json)` (`IMPORT_DELTA_REPLAY_HASH_MISMATCH` exit 4). Genesis v1.0.0 lineage verified via `genesis_template`. Untouched seed concepts in `grandfathered_concept_uris` exempt from grounding; zero mappings/evidence is never waivable (`ONT_EVO_UNGROUNDED_CONCEPT` exit 4). Destructive ops require `actor == "human"` (`IMPORT_AGENT_DESTRUCTIVE_OP_FORBIDDEN` exit 4); automated direct deltas reject `ONT_EVO_CONTRACT_VIOLATION` (exit 4). Replays SemVer bumps (`IMPORT_SEMVER_BUMP_MISMATCH` exit 4) asserting chain (`IMPORT_LINEAGE_BROKEN` exit 4), recording claimed attribution in `import_provenance.json` (`meta.json` immutable). Verify-only `matcher_sha256` in `Bm25MatcherRegistry` (missing `IMPORT_MATCHER_VERSION_MISMATCH` exit 4). Term-set mutations append `RescoreExternalMappingOp`s; `apply()` is pure. Import replay re-scores verify-only checking recorded `new_confidence` (closure `subClassOf` 1.0; mismatch `IMPORT_CONFIDENCE_MISMATCH` exit 4). Overrides, low confidence, or evidence grounding require admin `--acknowledge-unverified-import-attribution --acknowledgement-rationale <t>` in `import_provenance.json` (unack override `IMPORT_SELF_ACCEPTANCE_UNACKNOWLEDGED`, unack grounding `IMPORT_GROUNDING_VIOLATION` exit 4; missing `IMPORT_GROUNDING_RATIONALE_REQUIRED` exit 1; unack evidence demotes to `ONT_EVO_UNGROUNDED_CONCEPT`). Warnings reject `HISTORICAL_CONTRACT_WARNING_UNACKNOWLEDGED` exit 4 (waivable via rationale, missing `HISTORICAL_CONTRACT_RATIONALE_REQUIRED` exit 1).
    - **Privacy, Taint Reconstruction & Secrets**: Fresh `.session_secret` (0600) on import. Reconstructs taint by union of bundled `taint_index.json` and rebuilt index. `do_not_send_to_agent=True` strictly propagates taint.
4. **Isolated Session ID**: Fresh sanitized lowercase `session_id` per ADR-016 §2 (`^[a-z0-9_-]{1,64}$`, rejecting Windows reserved device names and route keywords).

### 3. Session Cloning Semantics
`POST /sessions/{id}/clone`: Allocates new `session_id`; copies CAS input blobs and `manifest.json` (`do_not_send_to_agent` preserved); generates fresh `.session_secret` (0600); reconstructs/re-pseudonymizes taint; replicates evidence and clarifications; copies `versions/vX/` byte-for-byte without mutating `meta.json` or `genesis_template_params`, recording `cloned_from_session_id` and optional `session_label` (from `[--session-label <l>]`, excluded from `genesis_template_params`) in `session.json`. Parity test asserts genesis hash is identical after clone.

## Consequences & Compliance
Zero-Trust Import blocks forged lineage and archive expansion attacks. Tests verify rejection of path traversal, size limit violations, tampered manifests, invalid deltas, provisional URIs, tampered replay, and pseudonym tokens. Round-trip tests confirm exported and imported sessions produce identical hashes.
