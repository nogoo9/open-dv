# ADR-011: Web Workbench Studio Interface at `/ontology` Using React Flow (`@xyflow/react`) and `elkjs`

## Status
Proposed

## Context
The Web Workbench (React 19 SPA) requires an interactive graph interface at `/ontology` with accessible DOM elements, deterministic hierarchical layout (Sugiyama), visual diffing, and route isolation to avoid bloating `/runs` or `/builder`.

## Decision
The Web Workbench interface at `/ontology` uses React Flow (`@xyflow/react`) and Eclipse Layout Kernel (`elkjs`):

### 1. React Flow (`@xyflow/react`) Canvas
Renders graph nodes as DOM elements in React 19: `ConceptNode` (Hub `hub_*`), `RelationshipNode` (Link `lnk_*`), `EnumerationNode` (Reference `ref_*`). Drag handles trigger Visual Editor.

### 2. Hierarchical Auto-Layout via `elkjs`
`elkjs` layered layout in a Web Worker (direction `RIGHT`/down) aligns taxonomy chains without freezing UI thread.

### 3. Visual Diff Overlay Mode
Compares versions: Added (green `+` badge), Removed (red strikethrough `-` badge), Modified (amber badge indicating changed attributes/mappings).

### 4. Lazy-Loaded Route Isolation
Route `/ontology` is dynamically imported in `apps/opendv-web-workbench/src/url-router.ts`; zero `@xyflow/react` or `elkjs` bytes load when visiting `/runs` or `/builder`.

## Consequences & Compliance
Accessible DOM canvas; `elkjs` layout; visual diff overlay; route isolation. Frontend tests (`bun test`) verify mounting, custom node rendering, and bundle isolation.
