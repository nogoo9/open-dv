# ADR-004: Python `rdflib` for OWL 2/Turtle and JSON-LD Parsing & Export

## Status
Proposed

## Context
Ingesting Semantic Web ontologies (OWL 2, RDFS, SKOS) and exporting Data Vault 2.0 Graph A in W3C Turtle (`.ttl`) and JSON-LD (`.jsonld`) requires robust, standard tooling.

## Decision
Python `rdflib` (7.x) in `packages/opendv-sources` and `packages/opendv-service` is the authoritative library for Semantic Web RDF operations:

1. **Reference Ingestion**: `ReferenceOntologyAdapter` uses `rdflib.Graph` to parse `.ttl`, `.rdf`, `.owl`, `.jsonld`, extracting Classes, hierarchy (`rdfs:subClassOf`), labels, definitions, and properties.
2. **Multi-Format Export**: Serializers convert versioned `GraphAOntology` into Turtle (`.ttl`, prefixes `dv2:`, `fibo-*:`, `owl:`, `rdfs:`, `skos:`, `xsd:`) and JSON-LD (`.jsonld`).
3. **Architectural Isolation**: `rdflib` is encapsulated within `opendv-sources` and `opendv-service`. `opendv-core` never imports `rdflib`.

## Consequences & Compliance
W3C compliance; pure-Python portability. Tests verify round-trip export preserving concepts, relationships, and mappings; metadata preserved via native CAS, `.odvstudio.zip`, or `dv2:` reified annotations.
