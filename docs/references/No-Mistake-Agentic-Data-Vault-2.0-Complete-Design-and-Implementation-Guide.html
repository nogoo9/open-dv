While Large Language Models (LLMs) can generate syntactically valid SQL and dbt macros at high velocity, unverified agent loops fail systematically when designing and maintaining enterprise Data Vault 2.0 (DV 2.0) warehouses. Models that compile cleanly and pass standard static SQL linters (sqlfluff) routinely introduce silent semantic, ontological, and evolutionary defects—creating source-aligned silos, selecting auto-incrementing surrogate keys as Hub Business Keys, over-modeling static lookup codes, breaking atomic business transactions into lossy binary Links, or mutating deployed Satellite hash signatures.

1. Ensuring Data Vault 2.0 Correctness: A Developer-Friendly Guide

For data engineers and application developers, the hardest part of Data Vault 2.0 is not writing SQL syntax—it is getting the business boundaries and keys right so that when new systems are onboarded six months later, existing tables never have to be rebuilt.

1.1 Why Naive AI Agents Fail at Data Vault 2.0 (The 5 Fatal Traps)

When you hand a raw Bronze database schema to a standard coding agent, it looks at one table at a time and guesses semantics from column names. Even though its SQL compiles cleanly, it falls into five classic traps:

Failure Mode What the Naive Agent Does Wrong Why It Happens How Our Pipeline Prevents It
1. The Source-System Vault Trap Creates separate Hubs for every source table (hub_sf_account, hub_sap_customer) instead of one shared hub_customer. The agent processes one table at a time without binding to a shared business glossary. Gate 1 Anti-Silo Rule: Forces every Hub to bind to a unique ontology concept (urn:ontology:entity:customer) and merges sources.
2. Surrogate Key Hallucination Picks an auto-incrementing integer (user_id = 48291) or random UUIDv4 as the Hub Business Key because it is 100% unique. The agent trusts _id column names without checking if that ID exists in any other system. Gate 2 Surrogate Ban: Statistical profiling detects sequential steps and random UUID entropy, blocking them when a natural key exists.
3. Reference Data Over-Modeling Turns static lookup codes (currency_code, iso_country, order_status) into full Hubs and Links. The agent treats every categorical string column as a core business entity. Algorithm A.2 Auto-Demotion: Automatically converts static low-cardinality Hubs (≤ 250 distinct values, 0 growth) into Reference Tables (ref_).
4. 3NF Link Decomposition & Optional FK Coupling Breaks an atomic 3-way order event into binary Links, or bakes an 85%-NULL promo_id column into the main Link hash key. The agent applies 3NF habits or bundles all foreign keys together regardless of nullability. Gate 3 & Algorithm A.4: Keeps mandatory keys (≥ 95\% populated) in the core N-ary Link and splits sparse optional FKs into binary Links.
5. Monolithic vs. Over-Split Satellites Either dumps 50 columns (mixing PII, static dates, and live counters) into 1 Satellite, or splits a tiny 8-column table into 5 tables. The agent cannot see real CDC update frequency, PII sensitivity tags, or byte write costs. Gate 4 & Algorithm A.1: Always isolates PII_HIGH/PCI into _pii Satellites, but only splits by update speed when wasted writes ≥ 50 MB/day.

2. Pragmatic Cold-Start (N=1) & Schema Evolution: Day-1 Simplicity with Multi-Source Stability

When onboarding the very first data source (N=1) in a domain, developers face a classic dilemma: you do not have a second data source yet to test cross-system key overlap, but the Hub and Link keys you pick on Day 1 are cryptographically permanent once downstream tables reference them.

  • If you under-engineer at N=1 (hashing local departmental IDs raw or bundling optional columns into Links), onboarding Source N=2 forces a destructive warehouse rebuild.
  • If you over-engineer at N=1 (splitting every small table into 5 velocity Satellites and pre-building empty Hubs), a simple 5-table source explodes into 35+ tables that slow down developer queries.

2.1 The Asymmetric Reversibility Matrix: What Must Be Locked on Day 1 vs. What Can Wait

Our pipeline solves the cold-start dilemma by separating decisions into Irreversible Cryptographic Invariants (enforced strictly on Day 1) and Additively Deferrable Constructs (suppressed via YAGNI guards until data scale or Source N=2 arrives):

Hub Concept Grain (Supertype vs. Subtype) High (Requires splitting Hub & migrating Satellite history) Lock Down on Day 1 Gate 1 Ontology Alignment: Enforces 1:1 binding to canonical business concepts.
Link Arity (Mandatory Kernel vs. Sparse FKs) High (Alters composite LK_* hash signature) Lock Down on Day 1 Gate 3.2 Nullable-FK Split: Only mandatory FKs (≥ 95\% non-null) enter the core Link kernel.

        for src in hub.business_key_sources:

            elif src.record_source_code in ontology[hub.concept_uri].authoritative_sors:
                src.tier, src.bkcc_prefix = "TIER_2_ENTERPRISE_SOR", None
            else:
                src.tier, src.bkcc_prefix = "TIER_3_LOCAL_SCOPED", src.record_source_code

    # 2. Keep mandatory FKs (>= 95% populated) in core Link; split sparse FKs (< 95%)
    for link in contract.n_ary_links:

        optional_fks  = [fk for fk in link.fks if profile.non_null_ratio(fk) <  0.95]
        if len(mandatory_fks) >= 2 and optional_fks:
            link.fks = mandatory_fks
            for opt_fk in optional_fks:
                contract.links.append(create_binary_link(link.driving_hub, opt_fk, where="NOT NULL"))

2.3 Preventing Table Bloat: The Gate 4 YAGNI Write-Amplification Guard

Splitting a Satellite by update speed saves storage writes (you avoid re-writing 20 static columns every time a live counter changes), but every extra Satellite adds another LEFT JOIN for analysts. At cold start, Algorithm A.1 keeps all non-PII columns in a single consolidated Satellite (CONSOLIDATED_YAGNI) unless all three quantitative conditions are met simultaneously:

  1. Column Width: The table has ≥ 10 non-PII descriptive columns.
  2. 100× Velocity Spread: Δ log10(λ) = log10(max λ + 10-6) - log10(min λ + 10-6) ≥ 2.0.
  3. Daily Write-Amplification Cost: Wamp = Nentities × max(λfast) × Σλ(c) ≤ 0.05 avgwidthbytes(c) ≥ 50 MB/day.

2.4 Continuous Evolution Lifecycle: Multi-Source (N → N+1) & Intra-Source Drift (Sk(t) → Sk(t+1))

If a naive agent adds a new column directly into an existing Satellite's HASHDIFF, 100% of historical records appear "changed" on the next load, duplicating millions of rows. Our pipeline handles all six evolution scenarios with zero table rebuilds:

3. Physical SQL Compilation, Hash Determinism & Shadow Sandbox Testing

Once the YAML contract passes semantic verification, our compiler generates physical dbt SQL models and verifies them at the Abstract Syntax Tree (AST) level using SQLGlot before running dynamic data tests in an isolated sandbox.

3.1 Node-Level AST Signatures & Layer Boundaries

Standard SQL linters check formatting; our SQLGlot verifier (Algorithm A.6) parses the compiled SQL syntax tree to enforce strict structural signatures and directed layer edges ([Bronze] -> [Staging (stg_)] -> [Raw Vault (hub_/lnk_/sat_)] -> [Business Vault (pit_/brd_/bv_sat_)] -> [Mart]):

Vault Archetype Mandatory Projected AST Columns Forbidden AST Patterns (Triggers Immediate Auto-Reject)
Stage (stg_) Raw source columns, derived HK_*, LK_*, HASHDIFF, LOAD_DTS, REC_SOURCE Filtering out rows (WHERE), aggregating (GROUP BY), or joining other staging tables.
Hub (hub_) Exactly 1 HK_<Entity>, Business Key(s), LOAD_DTS, REC_SOURCE Descriptive payload columns, foreign hash keys, HASHDIFF, or UPDATE/DELETE nodes.
Link (lnk_, nhl_, sal_, hal_) Exactly 1 LK_<Rel>, ≥ 2 parent HK_* keys, LOAD_DTS, REC_SOURCE Descriptive attributes (must live in a Link-Satellite), fewer than 2 Hub references.
Satellite (sat_, sat_eff_, mas_) Exactly 1 parent HK_*/LK_* (PK 1), LOAD_DTS (PK 2), HASHDIFF, REC_SOURCE, Payload Multiple parent Hub/Link keys, raw business keys, GROUP BY/HAVING, or multi-table joins in Raw Vault.

3.2 Cryptographic Hash Standardization & Ghost Record Determinism

The #1 silent killer in Data Vault 2.0 is inconsistent hash generation across staging tables—causing joins to drop rows silently. Algorithm A.5 rewrites every stg_* SQL AST so hash keys and HASHDIFF digests follow one exact mathematical standard:

  • Tier-1 / Tier-2 Unprefixed Business Key Hash (HK_*):
SHA256(CONCATWS('||', COALESCE(NULLIF(UPPER(TRIM(CAST(ci AS VARCHAR))), ''), '-1')))
  • Tier-3 BKCC-Prefixed Business Key Hash (HK_*):
SHA256(CONCATWS('||', 'PREFIX>', COALESCE(NULLIF(UPPER(TRIM(CAST(ci AS VARCHAR))), ''), '-1')))
  • Satellite HASHDIFF (Case-Preserving, Alphabetically Sorted Columns, '^^' Null Fallback):
SHA256(CONCATWS('||', COALESCE(NULLIF(TRIM(CAST(psorted, i AS VARCHAR)), ''), '^^')))

3.3 The Four Adversarial Shadow Sandbox Batches

Before any SQL model is allowed to merge, the pipeline spins up an ephemeral in-memory DuckDB instance or Snowflake Zero-Copy Clone and executes four synthetic adversarial test batches:

  1. Batch 1 (Ghost Record Integrity): Inserts the standard Unknown Ghost Record (0x0000...0000) and Error Ghost Record (0xFFFF...FFFF) and verifies that inner joins across Hubs, Links, and Satellites drop zero rows.
  2. Batch 2 (Strict Idempotency): Runs the full DAG load twice on identical Bronze micro-batches and asserts Δ rowcount = 0 across every Hub, Link, and Satellite.
  3. Batch 3 (Single-Attribute Delta Capture): Mutates a single descriptive attribute on 1 row out of 1,000 unchanged rows and asserts that the target Satellite inserts exactly 1 new row while sibling Satellites insert 0 rows.
  4. Batch 4 (N=1 → N=2 Cross-Source Collision & Integration Test): Injects synthetic overlapping Tier-1 keys and colliding Tier-3 local keys ('C-1042') from two sources. Asserts that Tier-1 keys merge into 1 Hub row while Tier-3 BKCC keys remain isolated as 2 distinct Hub rows without corrupting Satellite history.

6. Dedicated Architecture: Unstructured Data & Multi-Modal Integration in Data Vault 2.0

Over 80% of enterprise context—signed loan agreements, KYC passports, call-center recordings, underwriting emails, medical imaging reports, and vendor invoices—arrives as unstructured files. Traditional data warehouses ignore unstructured files completely, while modern AI pipelines frequently dump chunked text and embeddings into standalone vector stores with no historical auditability or key alignment to the enterprise data warehouse. Drawing upon data-vault metadata modeling research for data lakes (Oreščanin et al., IEEE Access 2024) and semantic graph integration (Cuba, Data Vault & Knowledge Graphs; The Data Vault Multiverse), our architecture introduces a formal Multi-Modal & Unstructured Data Vault 2.0 Subsystem.

6.1 The Four Architectural Tenets for Unstructured Data in Data Vault 2.0

To integrate unstructured artifacts without violating Data Vault 2.0's mathematical invariants (deterministic hashing, insert-only immutability, and strict separation of raw facts from soft business interpretations), Gate 5 enforces four non-negotiable rules:

  • Rule U1 — Object-Store Binary Separation & Cryptographic Manifests: Raw binary payloads (PDFs, audio, video, images) are stored in immutable Lakehouse Object Storage (S3/GCS/ADLS with Iceberg/Delta object tables). Relational Vault tables store only the canonical URI pointer, byte size, MIME metadata, and the content-addressable SHA256(raw_bytes) digest.
  • Rule U2 — Unstructured Artifacts as First-Class Hubs (hub_document): Every unstructured artifact is registered in hub_document (or hub_media_asset) keyed by its authoritative source document identifier (<DMS_SRC>||<doc_id>) or content-addressable hash, with physical file versions historized in sat_document_manifest.
  • Rule U3 — Strict Separation of Raw OCR/Text from Probabilistic AI Extractions: Deterministic file metadata (sat_document_manifest) and raw OCR/ASR text (split by Axis-2 PII boundary into sat_document_raw_pii and redacted sat_document_parsed_text) reside in the Raw Vault. Conversely, LLM-inferred entity mentions, sentiment, and extracted contract clauses are soft interpretations and MUST reside in the Business Vault.
  • Rule U4 — Model-Scoped Vector Satellite Isolation: Embedding vectors (e.g., 1,536-float arrays) mutate whenever the embedding model version changes. Embedding columns are strictly banned from standard descriptive Satellites and isolated into dedicated Business Vault Vector Satellites (sat_doc_chunk_vec_<model>) attached to deterministic document chunks (hub_document_chunk).

6.3 The 3-Tier Unstructured-to-Structured Entity Resolution Protocol

To prevent LLM entity-linking hallucinations from corrupting enterprise analytics, scout-unstructured and axi-dv Gate 5 classify every candidate link between a document chunk and a target Hub into three deterministic resolution tiers:

  1. Tier-U1: Deterministic Natural Key Regex / Checksum Extraction (Confidence = 1.00 • Auto-Commit): Before invoking an LLM, a deterministic regex/checksum scanner extracts all strings matching Tier-1 Global Standard patterns or Tier-2 Authoritative SoR patterns defined in Graph A (e.g., Singapore UEN 201912345K, LEI, IBAN, Policy Number, or Invoice ID). If the canonicalized hash SHA256(UPPER(TRIM(extracted_key))) matches an existing HK_* in the Raw Vault, lnk_document_entity_mention is committed automatically with EXTRACTION_TIER = 'TIER_U1_EXACT_KEY' and VERIFICATION_STATUS = 'VERIFIED'.

  2. Tier-U2: Multi-Attribute Lexical + Graph Neighborhood Resolution (0.85 ≤ Confidence < 1.00 • Guarded BV Commit): When a document refers to an entity by legal name and contextual attributes without an explicit UEN/ID (e.g., "Borrower: Pacific Marine Holdings Ltd, 80 Raffles Place" on a loan addendum signed on 2026-06-15), the resolver computes a composite score combining (a) Jaro-Winkler / trigram similarity against active sat_customer_* name/address columns and (b) graph neighborhood overlap (verifying whether that candidate HK_CUSTOMER participates in an active lnk_customer_loan within ± 30 days of the document date). Candidates scoring ≥ 0.85 with a separation margin ≥ 0.15 over the runner-up are committed to the Business Vault with EXTRACTION_TIER = 'TIER_U2_GRAPH_CONTEXT'.

  3. Tier-U3: Ambiguous or Low-Confidence Entity Mentions (Confidence < 0.85 or Multi-Entity Tie • Shadow Hold / Captain Escalation): When an extracted mention matches multiple Hub rows within a < 0.15 margin (e.g., three subsidiaries named "Pacific Marine...") or scores < 0.85, Gate 5 blocks insertion into lnk_document_entity_mention. The mention is routed to stg_unresolved_doc_mentions and surfaced via firstmate's needs-decision queue for human disambiguation. Once confirmed by the Captain, /stow-vault records the alias mapping in ref_entity_alias_crosswalk so future documents resolve at Tier-U1/U2 automatically.

Rather than operating as a custom binary or model wrapper, firstmate is a portable repository layout (AGENTS.md, .agents/skills/, skills/stow, bin/, and state/) that turns any primary coding harness (Claude Code, Grok, Pi, Oh My Pi, Codex, OpenCode, or Cursor) into a coordinating First Mate reporting to the human Captain:

  • Tiered Memory Curation and Decay (/stow): The built-in /stow skill sweeps completed sessions for uncaptured durable knowledge, reconciles open work ledgers, and curates tiered startup memory with time-horizon decay and cold archival so future sessions inherit institutional decisions without context bloat.

A.3 no-mistakes Gate Mechanics: Pre-Remote Proxy, Intent Grounding, and TOON Triage

Complementing firstmate's fleet orchestration, no-mistakes recognizes that when AI agents generate thousands of lines of code or SQL, the bottleneck shifts from authoring to validation. Instead of pushing directly to origin and suffering public CI churn, no-mistakes places a local validation proxy remote in front of upstream:

  • Transactional Disposable Worktree Gate (git push no-mistakes): Every push is intercepted into a clean, disposable worktree that executes a sequential validation pipeline: intent → rebase → review → test → document → lint → push → PR → CI (no-mistakes SKILL.md).
  • Mandatory Architectural Intent (--intent): When invoking no-mistakes axi run --intent "...", the agent must supply the explicit business goal, architectural decisions, and trade-offs chosen during the task. The Review critic uses --intent to distinguish deliberate design choices (such as an approved Tier-3 BKCC prefix or companion satellite split) from accidental regressions.
  • Non-Interactive TOON (axi) Protocol: Agents drive the gate headlessly via no-mistakes axi, which outputs compact Token-Oriented Object Notation (gate: <step>, findings[N]{id,severity,file,description,action}:, and help[N]:). The agent autonomously fixes auto-fix rows via axi respond --action fix, ignores no-op rows, and is strictly forbidden from bypassing ask-user rows—relaying them verbatim to the Captain.
  • Guarded History & Conflict Revalidation (ci.revalidate_repairs): When upstream advances while a worker is validating—or when CI repairs a merge conflict that rewrites commit history—the gate refuses to force-push unreviewed history and routes the rebased diff back through the Review and Test gates automatically.

Algorithm A.1: 3-Axis Satellite Partitioning Codemod with Cold-Start Write-Amplification Guard

from __future__ import annotations
import math
from copy import deepcopy
from typing import Any, Dict, List

SENSITIVE_TAGS = {"PII_HIGH", "PCI"}

def codemod_split_satellites_3axis(
    contract: Dict[str, Any],
    bronze_profile: Dict[str, Dict[str, Dict[str, Any]]],
    min_cols_for_volatility_split: int = 10,
    log_spread_threshold: float = 2.0,  # 10^2 = 100x rate-of-change spread
    write_amp_threshold_bytes_per_day: float = 50 * 1024 * 1024,  # 50 MB/day YAGNI guard
    epsilon: float = 1e-6,
) -> Dict[str, Any]:
    """
    Deterministically splits Satellites across:
    1. Governance/PII isolation (_pii) -> Always enforced, even at Cold Start (N=1).
    2. Empirical CDC log-volatility tiers (_static, _core, _high_freq) -> Enforced only
       when column width, log-volatility spread, AND daily byte write-amplification
       exceed the Cold-Start YAGNI thresholds.
    Synchronizes column_triage_ledger in-place.
    """
    mutated = deepcopy(contract)
    new_satellites: List[Dict[str, Any]] = []
    ledger_remap: Dict[tuple[str, str], str] = {}

    for sat in mutated.get("satellites", []):
        if sat["satellite_type"] != "STANDARD_SATELLITE":
            new_satellites.append(sat)
            continue

        b_table = sat["source_bronze_table"]
        base_name = sat["name"]
        payload: List[str] = sat.get("payload_columns", [])
        table_profile = bronze_profile.get(b_table, {})

        # Step 1: Partition PII / PCI columns from General payload (Always active)
        sensitive_cols: List[str] = []
        general_cols: List[str] = []

        for col in sorted(payload):
            col_meta = table_profile.get(col, {})
            sec_tag = col_meta.get("security_classification", "INTERNAL")
            if sec_tag in SENSITIVE_TAGS:
                sensitive_cols.append(col)
            else:
                general_cols.append(col)

        if sensitive_cols:
            pii_sat_name = f"{base_name}_pii" if not base_name.endswith("_pii") else base_name
            pii_sat = deepcopy(sat)
            pii_sat["name"] = pii_sat_name
            pii_sat["security_classification"] = "PII_HIGH"
            pii_sat["volatility_tier"] = "STANDARD"
            pii_sat["payload_columns"] = sorted(sensitive_cols)
            new_satellites.append(pii_sat)
            for c in sensitive_cols:
                ledger_remap[(b_table, c)] = pii_sat_name

        if not general_cols:
            continue

        # Step 2: Evaluate log10 CDC volatility spread & Daily Write-Amplification Cost
        log_vols: Dict[str, float] = {}
        raw_vols: Dict[str, float] = {}
        col_widths: Dict[str, float] = {}
        entity_count = 1

        for col in general_cols:
            c_prof = table_profile.get(col, {})
            lam = float(c_prof.get("cdc_lambda_per_day", 0.0))
            width = float(c_prof.get("avg_width_bytes", 32.0))
            entity_count = max(entity_count, int(c_prof.get("table_row_count", 1000)))
            raw_vols[col] = lam
            log_vols[col] = math.log10(lam + epsilon)
            col_widths[col] = width

        v_spread = max(log_vols.values()) - min(log_vols.values()) if len(general_cols) > 1 else 0.0
        max_lambda = max(raw_vols.values()) if raw_vols else 0.0
        slow_bytes = sum(col_widths[c] for c in general_cols if raw_vols[c] <= 5e-2)
        daily_write_amp_bytes = entity_count * max_lambda * slow_bytes

        # Cold-Start YAGNI Guard: Keep a single Satellite unless all 3 thresholds are breached
        should_split_volatility = (
            len(general_cols) >= min_cols_for_volatility_split
            and v_spread >= log_spread_threshold
            and daily_write_amp_bytes >= write_amp_threshold_bytes_per_day
        )

        if not should_split_volatility:
            clean_sat = deepcopy(sat)
            clean_sat["name"] = base_name
            clean_sat["security_classification"] = "INTERNAL"
            clean_sat["volatility_tier"] = "STANDARD"
            clean_sat["payload_columns"] = sorted(general_cols)
            new_satellites.append(clean_sat)
            for c in general_cols:
                ledger_remap[(b_table, c)] = base_name
            continue

        # Step 3: Partition into STATIC (<= 1e-3), STANDARD (1e-3 .. 5e-2), HIGH_FREQ (> 5e-2)
        tiers: Dict[str, List[str]] = {"STATIC": [], "STANDARD": [], "HIGH_FREQ": []}
        for col in general_cols:
            lam = raw_vols[col]
            if lam <= 1e-3:
                tiers["STATIC"].append(col)
            elif lam <= 5e-2:
                tiers["STANDARD"].append(col)
            else:
                tiers["HIGH_FREQ"].append(col)

        suffix_map = {"STATIC": "static", "STANDARD": "core", "HIGH_FREQ": "high_freq"}

        for tier_key, cols in tiers.items():
            if not cols:
                continue
            tier_sat_name = f"{base_name}_{suffix_map[tier_key]}"
            tier_sat = deepcopy(sat)
            tier_sat["name"] = tier_sat_name
            tier_sat["security_classification"] = "INTERNAL"
            tier_sat["volatility_tier"] = tier_key
            tier_sat["payload_columns"] = sorted(cols)
            new_satellites.append(tier_sat)
            for c in cols:
                ledger_remap[(b_table, c)] = tier_sat_name

    mutated["satellites"] = new_satellites

    # Step 4: Synchronize the Column Triage Ledger
    for entry in mutated.get("column_triage_ledger", []):
        key = (entry["bronze_table"], entry["column_name"])
        if key in ledger_remap and entry["elm_classification"] == "DESCRIPTIVE_PAYLOAD":
            entry["target_dv_entity"] = ledger_remap[key]

    return mutated

def codemod_demote_enum_hubs_to_ref(

            ref_name = f"ref_{concept_slug}"
            demoted_hubs[hub["name"]] = ref_name

            for sat in mutated.get("satellites", []):
                if sat["parent_entity"] == hub["name"]:
                    desc_cols.extend(sat.get("payload_columns", []))

            primary_src = hub["business_key_sources"][0]
            enum_uri = uri.replace(":entity:", ":enum:")
            mutated.setdefault("reference_tables", []).append({
                "name": ref_name,
                "ontology_concept_uri": enum_uri,
                "source_bronze_table": primary_src["bronze_table"],
                "code_column": primary_src["key_columns"][0],
                "description_columns": sorted(set(desc_cols)),
            })
        else:
            retained_hubs.append(hub)

    if not demoted_hubs:
        return mutated

    mutated["hubs"] = retained_hubs
    mutated["satellites"] = [
        sat for sat in mutated.get("satellites", [])
        if sat["parent_entity"] not in demoted_hubs

            for d_ref in demoted_refs:
                degen.extend(d_ref["source_fk_columns"])

            retained_links.append(lnk)
        elif len(real_refs) == 1:
            real_hub = real_refs[0]["target_hub"]
            fk_cols: List[str] = []
            for d_ref in demoted_refs:
                fk_cols.extend(d_ref["source_fk_columns"])

            (
                s for s in mutated["satellites"]
                if s["parent_entity"] == real_hub and s["source_bronze_table"] == b_table

            None,
        )

            target_sat["payload_columns"] = sorted(merged_payload)

    for entry in mutated.get("column_triage_ledger", []):
        if entry["target_dv_entity"] in demoted_hubs:
            entry["elm_classification"] = "REFERENCE_CODE"
            entry["target_dv_entity"] = demoted_hubs[entry["target_dv_entity"]]

    return mutated

from typing import Any, Dict, List

def codemod_enforce_cold_start_extensibility(
    contract: Dict[str, Any],
    ontology_graph: Dict[str, Dict[str, Any]],
    bronze_profile: Dict[str, Dict[str, Dict[str, Any]]],
    mandatory_fk_non_null_threshold: float = 0.95,

    Enforces Cold-Start (N=1) extensibility invariants:
    1. 3-Tier Business Key Authority & BKCC collision prefixing on Hub keys.

    # Part 1: Enforce 3-Tier Business Key Authority & BKCC on Hubs
    for hub in mutated.get("hubs", []):
        uri = hub["ontology_concept_uri"]
        concept_meta = ontology_graph.get(uri, {})

        for src in hub.get("business_key_sources", []):

                bronze_profile.get(b_table, {}).get(c, {}).get("pattern_class") == "GLOBAL_STANDARD_CODE"

                src["key_authority_tier"] = "TIER_1_GLOBAL_STANDARD"
                src["require_src_qualifier"] = False
                src["bkcc_prefix"] = None
            elif is_tier2_sor:
                src["key_authority_tier"] = "TIER_2_ENTERPRISE_SOR"
                src["require_src_qualifier"] = False
                src["bkcc_prefix"] = None
            else:
                src["key_authority_tier"] = "TIER_3_LOCAL_SCOPED"
                src["require_src_qualifier"] = True
                src["bkcc_prefix"] = rec_src

    # Part 2: Split sparse/nullable FKs out of N-ary Links (N >= 3)
    rewired_links: List[Dict[str, Any]] = []
    ledger_fk_remap: Dict[tuple[str, str], str] = {}

    for lnk in mutated.get("links", []):
        refs = lnk.get("hub_references", [])
        if len(refs) < 3 or lnk["link_type"] not in {"STANDARD_LINK", "NON_HISTORIZED_LINK"}:
            rewired_links.append(lnk)
            continue

        table_prof = bronze_profile.get(b_table, {})

        for ref in refs:

                float(table_prof.get(fk_col, {}).get("non_null_ratio", 1.0))
                for fk_col in ref["source_fk_columns"]

            rewired_links.append(core_lnk)

            base_slug = lnk["name"].replace("lnk_", "", 1).replace("nhl_", "", 1)

                    "name": opt_lnk_name,
                    "link_type": "STANDARD_LINK",
                    "ontology_concept_uri": lnk["ontology_concept_uri"],

                    "driving_key_hub": anchor_ref["target_hub"],

                    "degenerate_columns": [],
                    "hub_references": [anchor_ref, opt_ref],

                rewired_links.append(opt_lnk)
                for fk_col in opt_ref["source_fk_columns"]:
                    ledger_fk_remap[(b_table, fk_col)] = opt_lnk_name

            rewired_links.append(lnk)

        if key in ledger_fk_remap:

            entry["target_dv_entity"] = ledger_fk_remap[key]

    return mutated

from typing import Dict, List, Optional, Tuple
import sqlglot
from sqlglot import exp

def build_canonical_column_standardization_ast(
    col_name: str,
    is_business_key: bool = True,
) -> exp.Expression:
    """
    Constructs the exact SQLGlot AST for Data Vault 2.0 column standardization:
    - Business Keys: COALESCE(NULLIF(UPPER(TRIM(CAST(col AS VARCHAR))), ''), '-1')
    - Satellite Payload: COALESCE(NULLIF(TRIM(CAST(col AS VARCHAR)), ''), '^^')
    """
    cast_expr = exp.Cast(
        this=exp.column(col_name),
        to=exp.DataType.build("VARCHAR"),
    )
    trim_expr = exp.Trim(this=cast_expr)
    core_str = exp.Upper(this=trim_expr) if is_business_key else trim_expr
    nullif_expr = exp.Nullif(this=core_str, expression=exp.Literal.string(""))
    fallback = "-1" if is_business_key else "^^"
    return exp.Coalesce(this=nullif_expr, expressions=[exp.Literal.string(fallback)])

def build_canonical_sha256_hash_ast(
    columns: List[str],
    alias_name: str,
    is_business_key: bool = True,
    sort_alphabetically: bool = False,
    bkcc_prefix: Optional[str] = None,
) -> exp.Alias:
    """
    Builds the canonical SHA256(CONCAT_WS('||', ...)) SQLGlot AST node.
    - If bkcc_prefix is set (Tier-3 local key), prepends the BKCC literal into CONCAT_WS.
    - For Business Keys (is_business_key=True), preserves semantic composite key order.
    - For Satellite HASHDIFF (sort_alphabetically=True), enforces strict lexicographical order.
    """
    ordered_cols = sorted(columns) if sort_alphabetically else list(columns)
    standardized_args: List[exp.Expression] = []

    if is_business_key and bkcc_prefix:
        standardized_args.append(exp.Literal.string(bkcc_prefix.strip().upper()))

    for c in ordered_cols:
        standardized_args.append(
            build_canonical_column_standardization_ast(c, is_business_key=is_business_key)
        )

    concat_ws = exp.Anonymous(
        this="CONCAT_WS",
        expressions=[exp.Literal.string("||"), *standardized_args],
    )
    sha256_call = exp.Anonymous(this="SHA256", expressions=[concat_ws])
    return exp.alias_(sha256_call, alias_name)

def codemod_enforce_staging_hashes_sql(
    raw_sql: str,
    hub_keys: Dict[str, Tuple[List[str], Optional[str]]],
    satellite_hashdiffs: Dict[str, List[str]],
    dialect: str = "snowflake",
) -> str:
    """
    Parses a Staging SQL model via SQLGlot, removes any existing non-compliant HK_*
    or HASHDIFF_* projections, and injects canonical AST expressions.
    hub_keys maps: hk_alias -> (list_of_key_columns, optional_bkcc_prefix)
    """
    parsed = sqlglot.parse_one(raw_sql, read=dialect)
    select_node = parsed.find(exp.Select)
    if select_node is None:
        raise ValueError("Staging SQL model must contain a valid SELECT expression.")

    target_aliases = set(hub_keys.keys()) | set(satellite_hashdiffs.keys())

    cleaned_projections = [
        proj for proj in select_node.expressions
        if proj.alias_or_name not in target_aliases
    ]

    for hk_alias, (bk_cols, bkcc_prefix) in hub_keys.items():
        cleaned_projections.append(
            build_canonical_sha256_hash_ast(
                columns=bk_cols,
                alias_name=hk_alias,
                is_business_key=True,
                sort_alphabetically=False,
                bkcc_prefix=bkcc_prefix,
            )
        )

    for hd_alias, payload_cols in satellite_hashdiffs.items():
        cleaned_projections.append(
            build_canonical_sha256_hash_ast(
                columns=payload_cols,
                alias_name=hd_alias,
                is_business_key=False,
                sort_alphabetically=True,
                bkcc_prefix=None,
            )
        )

    select_node.set("expressions", cleaned_projections)
    return parsed.sql(dialect=dialect, pretty=True)

from typing import List
import sqlglot
from sqlglot import exp

def verify_physical_dv2_sql_ast(
    model_name: str,
    sql_text: str,
    dialect: str = "snowflake",
) -> List[str]:
    """
    Parses compiled Data Vault 2.0 SQL via SQLGlot and enforces physical AST invariants:
    1. Insert-Only guarantee (no UPDATE, DELETE, TRUNCATE, DROP).
    2. Entity column signature contracts for hub_*, lnk_*, sat_*, and stg_*.
    3. Raw Vault purity (no GROUP BY, HAVING, or multi-source joins inside Raw Satellites).
    """
    violations: List[str] = []
    parsed = sqlglot.parse_one(sql_text, read=dialect)

    # 1. Insert-Only Guarantee
    forbidden_mutations = (exp.Delete, exp.Update, exp.TruncateTable, exp.Drop)
    if parsed.find(*forbidden_mutations):
        violations.append(
            f"AST_ERROR [{model_name}]: Contains destructive DML/DDL node. Raw Vault is strictly Insert-Only."
        )

    select_node = parsed.find(exp.Select)
    if select_node is None:
        violations.append(f"AST_ERROR [{model_name}]: Missing valid SELECT projection.")
        return violations

    projected_cols = {proj.alias_or_name.upper() for proj in select_node.expressions}

    # 2. Mandatory Audit Columns Check
    for audit_col in ("LOAD_DTS", "REC_SOURCE"):
        if audit_col not in projected_cols:
            violations.append(f"AST_ERROR [{model_name}]: Missing mandatory audit column '{audit_col}'.")

    # 3. Archetype-Specific Structural Checks
    if model_name.startswith("hub_"):
        hk_cols = [c for c in projected_cols if c.startswith("HK_")]
        if len(hk_cols) != 1:
            violations.append(f"AST_ERROR [{model_name}]: Hub must project exactly 1 HK_* column; found {hk_cols}.")
        if "HASHDIFF" in projected_cols or any(c.startswith("HASHDIFF") for c in projected_cols):
            violations.append(f"AST_ERROR [{model_name}]: Hubs cannot contain HASHDIFF columns.")

    elif model_name.startswith(("lnk_", "nhl_", "sal_", "hal_")):
        lk_cols = [c for c in projected_cols if c.startswith(("LK_", "HK_LINK_"))]
        hk_refs = [c for c in projected_cols if c.startswith("HK_") and not c.startswith("HK_LINK_")]
        if len(lk_cols) != 1:
            violations.append(f"AST_ERROR [{model_name}]: Link must project 1 Link Hash Key; found {lk_cols}.")
        if len(hk_refs) < 2:
            violations.append(f"AST_ERROR [{model_name}]: Link must reference >= 2 Hub Hash Keys; found {hk_refs}.")

    elif model_name.startswith("sat_"):
        parent_keys = [c for c in projected_cols if c.startswith(("HK_", "LK_"))]
        if len(parent_keys) != 1:
            violations.append(
                f"AST_ERROR [{model_name}]: Satellite must reference exactly 1 parent HK_*/LK_*; found {parent_keys}."
            )
        if not model_name.startswith("sat_eff_") and not any(c.startswith("HASHDIFF") for c in projected_cols):
            violations.append(f"AST_ERROR [{model_name}]: Standard Satellite must project a HASHDIFF column.")

    # 4. Raw Vault Purity Check (No Aggregations in Raw Vault)
    if model_name.startswith(("hub_", "lnk_", "sat_")):
        if parsed.find(exp.Group) or parsed.find(exp.Having):
            violations.append(
                f"AST_ERROR [{model_name}]: Aggregations (GROUP BY / HAVING) are forbidden in Raw Vault models."
            )

    return violations

            if cand_src.get("bkcc_prefix") != dep_src.get("bkcc_prefix"):
                errors.append(
                    f"EVOLUTION_ERROR [BKCC_MUTATED]: Hub '{h_name}' source {src_key} "
                    f"altered bkcc_prefix from '{dep_src.get('bkcc_prefix')}' to '{cand_src.get('bkcc_prefix')}'."
                )

    # 2. Verify Link backwards compatibility (composite FK order & arity lock)
    cand_links = {l["name"]: l for l in candidate_contract.get("links", [])}
    for dep_lnk in deployed_contract.get("links", []):
        l_name = dep_lnk["name"]
        if l_name not in cand_links:
            errors.append(
                f"EVOLUTION_ERROR [LINK_DELETED]: Deployed Link '{l_name}' was removed in candidate contract."
            )
            continue

        cand_lnk = cand_links[l_name]
        dep_sig = [
            (r["target_hub"], r["role_alias"], tuple(r["source_fk_columns"]))
            for r in dep_lnk.get("hub_references", [])
        ]
        cand_sig = [
            (r["target_hub"], r["role_alias"], tuple(r["source_fk_columns"]))
            for r in cand_lnk.get("hub_references", [])
        ]
        if dep_sig != cand_sig:
            errors.append(
                f"EVOLUTION_ERROR [LINK_ARITY_OR_ORDER_MUTATED]: Deployed Link '{l_name}' "
                f"changed hub_references signature from {dep_sig} to {cand_sig}. "
                f"Create a new Link instead of mutating an existing Link's composite hash."
            )

    return errors

from typing import Any, Dict, Optional, Tuple

def run_axi_dv_verification_pipeline(
    candidate_contract: Dict[str, Any],
    ontology_graph: Dict[str, Dict[str, Any]],
    bronze_profile: Dict[str, Dict[str, Dict[str, Any]]],
    bronze_link_cdc_profile: Dict[str, Dict[str, float]],
    deployed_contract: Optional[Dict[str, Any]] = None,
) -> Tuple[str, Dict[str, Any], list[str]]:
    """
    Executes the complete No-Mistake Data Vault 2.0 verification and codemod loop.
    Returns:
      status: "PASS" | "REJECT_WITH_TRACE" | "ASK_USER"
      transformed_contract: Codemodded contract dictionary
      diagnostics: Structured compiler error traces or human escalation prompts
    """
    diagnostics: list[str] = []

    # 0. Check for explicit human architect escalations emitted by the agent
    if candidate_contract.get("unmapped_escalations"):
        for esc in candidate_contract["unmapped_escalations"]:
            diagnostics.append(
                f"ASK_USER [{esc['escalation_reason']}] on {esc['bronze_table']} "
                f"({esc['columns']}): {esc['architect_question']}"
            )
        return "ASK_USER", candidate_contract, diagnostics

    # 1. Execute Deterministic Graph Codemods (`auto-fix` stage)
    contract = codemod_demote_enum_hubs_to_ref(
        candidate_contract, ontology_graph, bronze_profile
    )
    contract = codemod_enforce_cold_start_extensibility(
        contract, ontology_graph, bronze_profile
    )
    contract = codemod_inject_link_effectivity(
        contract, bronze_link_cdc_profile
    )
    contract = codemod_split_satellites_3axis(
        contract, bronze_profile
    )

    # 2. Gate 0 Assertion: Additive Evolution Lock (if upgrading an existing Vault N -> N+1)
    if deployed_contract is not None:
        diagnostics.extend(
            verify_additive_evolution_invariants(deployed_contract, contract)
        )

    # 3. Gate 1 Assertion: Anti-Silo Ontology Uniqueness & Zero-Phantom-Entity Check
    seen_concepts: Dict[str, str] = {}
    active_entities = {
        entry["target_dv_entity"]
        for entry in contract.get("column_triage_ledger", [])
    }

    for hub in contract.get("hubs", []):
        uri = hub["ontology_concept_uri"]
        if uri in seen_concepts:
            diagnostics.append(
                f"SEMANTIC_ERROR [Gate 1 - ANTI_SILO_VIOLATION]: Both '{seen_concepts[uri]}' "
                f"and '{hub['name']}' bind to '{uri}'. Consolidate into a single canonical Hub."
            )
        seen_concepts[uri] = hub["name"]

        if hub["name"] not in active_entities:
            diagnostics.append(
                f"SEMANTIC_ERROR [Gate 1 - PHANTOM_HUB_REJECTED]: Hub '{hub['name']}' has no "
                f"mapped physical columns in column_triage_ledger."
            )

    # 4. Gate 2 Assertion: Surrogate Key Ban when Natural Key Exists
    for hub in contract.get("hubs", []):
        for src in hub["business_key_sources"]:
            b_table = src["bronze_table"]
            for k_col in src["key_columns"]:
                prof = bronze_profile.get(b_table, {}).get(k_col, {})
                pat = prof.get("pattern_class", "UNKNOWN")
                if pat in {"MONOTONIC_INT", "RANDOM_UUID_V4"} and not src.get("system_scoped_bk_justification"):
                    diagnostics.append(
                        f"SEMANTIC_ERROR [Gate 2 - SURROGATE_KEY_REJECTED]: Hub '{hub['name']}' "
                        f"uses column '{b_table}.{k_col}' classified as '{pat}' without justification. "
                        f"Select a natural business key or provide system_scoped_bk_justification."
                    )

    if diagnostics:
        return "REJECT_WITH_TRACE", contract, diagnostics

    return "PASS", contract, ["ALL_GATES_GREEN: Contract verified and cold-start codemods applied."]

from typing import Any, Dict, List, Tuple

def codemod_intra_source_schema_drift(
    deployed_contract: Dict[str, Any],
    candidate_contract: Dict[str, Any],
    schema_epoch_tag: str = "v2",
) -> Dict[str, Any]:
    """
    Algorithm A.9a: Zero-Rehash Intra-Source Schema Drift Codemod.
    When an already-deployed Satellite gains new descriptive columns from an existing
    Bronze table, automatically isolates the newly added columns into an additive
    companion Satellite (sat_<entity>_<src>_ext_<epoch>) so historical HASHDIFF digests
    in the primary Satellite remain 100% immutable.
    """
    deployed_sats = {s["name"]: s for s in deployed_contract.get("satellites", [])}
    updated_satellites: List[Dict[str, Any]] = []

    for sat in candidate_contract.get("satellites", []):
        s_name = sat["name"]
        if s_name not in deployed_sats:
            updated_satellites.append(sat)
            continue

        dep_sat = deployed_sats[s_name]
        dep_cols = set(dep_sat.get("payload_columns", []))
        cand_cols = set(sat.get("payload_columns", []))

        added_cols = sorted(cand_cols - dep_cols)
        removed_cols = sorted(dep_cols - cand_cols)

        # Preserve original payload columns on the deployed Satellite (soft-tombstoning removed cols in stg_)
        sat["payload_columns"] = sorted(dep_cols)
        if removed_cols:
            sat["soft_deprecated_columns"] = removed_cols
        updated_satellites.append(sat)

        # Spin off newly added columns into an additive companion Satellite
        if added_cols:
            updated_satellites.append({
                "name": f"{s_name}_ext_{schema_epoch_tag}",
                "satellite_type": sat["satellite_type"],
                "parent_entity": sat["parent_entity"],
                "source_bronze_table": sat["source_bronze_table"],
                "security_classification": sat.get("security_classification", "INTERNAL"),
                "volatility_tier": "ADDITIVE_DRIFT_COMPANION",
                "payload_columns": added_cols,
            })

    candidate_contract["satellites"] = updated_satellites
    return candidate_contract


def verify_gate5_unstructured_invariants(
    contract: Dict[str, Any],
    parsed_doc_samples: Dict[str, str],
) -> List[str]:
    """
    Algorithm A.9b: Gate 5 Verifier for Unstructured Data Vault 2.0 Integration.
    Enforces binary/vector isolation, provenance satellites on AI links, and exact
    character-span substring verification on LLM-extracted Business Vault attributes.
    """
    errors: List[str] = []
    sats_by_parent: Dict[str, List[Dict[str, Any]]] = {}

    for sat in contract.get("satellites", []):
        sats_by_parent.setdefault(sat["parent_entity"], []).append(sat)
        if sat.get("satellite_type") == "STANDARD_SATELLITE":
            for col in sat.get("payload_columns", []):
                if any(k in col.lower() for k in ("raw_blob", "embedding_vec", "binary_bytes")):
                    errors.append(
                        f"GATE5_ERROR [BLOB_OR_VEC_IN_RAW_SAT]: Satellite '{sat['name']}' "
                        f"includes '{col}'. Isolate binary files in Object Storage and "
                        f"embeddings in a dedicated VECTOR_SATELLITE."
                    )

    for lnk in contract.get("links", []):
        if lnk.get("link_type") == "UNSTRUCTURED_EXTRACTION_LINK":
            attached = sats_by_parent.get(lnk["name"], [])
            req_cols = {"extractor_model_id", "confidence_score", "evidence_quote"}
            if not any(
                s.get("satellite_type") == "AI_PROVENANCE_SATELLITE"
                and req_cols.issubset(set(s.get("payload_columns", [])))
                for s in attached
            ):
                errors.append(
                    f"GATE5_ERROR [MISSING_PROVENANCE_SAT]: Unstructured Link '{lnk['name']}' "
                    f"must attach an AI_PROVENANCE_SATELLITE containing {sorted(req_cols)}."
                )

    for sample in contract.get("sample_extractions", []):
        doc_id = sample["doc_id"]
        quote = sample.get("evidence_quote", "")
        start, end = sample.get("char_start", 0), sample.get("char_end", 0)
        body = parsed_doc_samples.get(doc_id, "")
        if not quote or body[start:end] != quote:
            errors.append(
                f"GATE5_ERROR [SPAN_HALLUCINATION]: Extracted attribute '{sample.get('attribute')}' "
                f"in document '{doc_id}' failed exact substring verification at [{start}:{end}]."
            )

    return errors
