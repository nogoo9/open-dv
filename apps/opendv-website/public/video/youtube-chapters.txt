Open-DV V2 — Agent-First 7-Step Data Vault 2.0 Workbench Walkthrough (2:45)

Turn messy enterprise data into certified, multi-target Data Vault 2.0 — before any 5-Zone (Z0–Z4) SQL runs.
Open-DV V2 pairs a 7-Step Guided ⇄ Observatory Workbench over 5-table project.sqlite with JobMcpBroker (/coord & /scout), Budget Meter telemetry, bounded L1 + V1–V8 CEGAR verification (including V8 Horizon Critic BRK-01..08), and compilation to 11 storage targets.

Quick Start (Apache-2.0):
  git clone https://github.com/nogoo9/open-dv.git
  cd open-dv
  uv sync --all-packages
  uv run opendv serve

Web Workbench (Project Workflow | DV Schema Explorer | Run Explorer | Settings):
  http://127.0.0.1:8420  (zero-auth loopback open access; --allow-remote-unauthenticated required for non-loopback)

Headless CLI & 17-Tool Stdio MCP (Unified `opendv` CLI):
  uv run opendv project init my-vault --domain asset_management
  uv run opendv source attach my-vault --type sqlite --path ./data/public_am/am_sec_treasury_ibor.sqlite
  uv run opendv ontology fibo-qa "FinancialInstrument"
  uv run opendv vault build my-vault --profile balanced --json
  uv run opendv vault logs my-vault --run-id run6-8bb5f57211
  uv run opendv storage query my-vault --sql "SELECT COUNT(*) AS row_count FROM raw_vault.hub_holding"
