Open-DV v6.0 — Neuro-Symbolic Data Vault 2.0 Architecture Walkthrough (2:45)

Turn messy enterprise data into verified Data Vault 2.0 — before a single SQL line runs.
Open-DV pairs multi-agent semantic discovery (@vault-first-mate, @scout-source, @scout-unstructured, @ship-vault) with a deterministic 6-gate formal verifier (axi-dv, Gates G0-G5) and in-memory DuckDB 4-Zone shadow sandbox.

Quick Start (Apache-2.0):
  git clone https://github.com/nogoo9/open-dv.git
  cd open-dv
  uv sync --all-packages && bun install
  uv run opendv serve --open

Web UI (Ontology Studio, 4-Step Pipeline Builder & 3-Level Explorer):
  http://127.0.0.1:8420

Headless CI Verification (Dual CLIs):
  uv run opendv verify -c final_contract.yaml --json
  opendvctl pipeline run --api-url "$OPENDV_API_URL" -i pipeline_input.yaml --json
