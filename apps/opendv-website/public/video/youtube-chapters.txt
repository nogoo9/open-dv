Open-DV — Neuro-Symbolic Data Vault 2.0 & Unified 6-Step Wizard Walkthrough (2:45)

Turn messy enterprise data into verified Data Vault 2.0 — before a single SQL line runs.
Open-DV pairs Agent-first discovery in the 4-Tab Workbench with a deterministic 6-gate formal verifier (axi-dv, Gates G0-G5), in-memory DuckDB shadow sandbox, and 5-Zone (Z0-Z4) compiler (bronze, staging, raw_vault, business_vault, information_mart).

Quick Start (Apache-2.0):
  git clone https://github.com/nogoo9/open-dv.git
  cd open-dv
  uv sync --all-packages && bun install
  uv run opendv serve --open

Web Workbench (Ontology & Pipeline | DV Schema Explorer | Run Explorer | Settings):
  http://127.0.0.1:8420  (loopback zero-auth open access; --allow-remote-unauthenticated required for non-loopback)

Headless CI Verification & New Subcommands (Dual CLIs):
  uv run opendv verify -c final_contract.yaml --json
  uv run opendv run dv-schema --run-id run_09f4c2 --sql "SELECT * FROM information_mart.vw_position_current LIMIT 20"
  opendvctl ontology studio logs --session <id> --follow
