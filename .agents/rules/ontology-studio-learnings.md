# Ontology Studio & Platform Hardening Guardrails

Mandatory engineering checklist distilled from building and dual-model auditing (`docs/24-ontology-studio-engineering-learnings.md`) the `open-dv` Ontology Construction Studio. Apply these invariants whenever modifying CAS/hashing, locks, FastAPI/SSE, CLIs, Web Workbench, or documentation.

## 1. Cryptographic Digests & RFC 8785 JCS
- **No Placeholder Digests:** Never invent hex digests in specs, ADRs, fixtures, or tests. Compute digests from real RFC 8785 JCS preimages (`compute_ontology_sha256` / `dumps_jcs_bytes`; genesis `0.0.0` Graph A = `1916a5c6d501015984b887fd76609b225b72d5d393e5813d8df210b92ab3b4c9`; certified PE baseline = `1c100409cbbe12051f7211d2d6d6838670982b9164aaf18b52f566864da90b81`).
- **Disk Byte == Digest Preimage:** Always write `dumps_jcs_bytes(canonicalize_graph_a_dict(ont))` to CAS so `sha256(disk_bytes) == target_sha256`.
- **Preserve Certified Baselines:** Scope empty-field pruning (`_norm_empty`) strictly to post-baseline extension fields; never re-sort concept `attributes` or prune legacy root lists (`canonical_relationships`, `reference_enumerations`, `standards_references`, `decision_refs`).
- **No Lossy Client Exports:** When an active server session exists, fetch canonical exports from `/export` and surface server errors loudly rather than substituting lossy client-side Graph A reconstructions.

## 2. Windows / POSIX Locks, ACLs & Processes
- **Single Lock Protocol (`L1 -> L5`) & Task-Scoped Reentrancy:** Never mix lock implementations or write lock metadata over locked `msvcrt.locking` byte ranges (`WinError 33`). Key `ContextVar` lock reentrancy on `(thread_id, task_id, is_locked)` so `asyncio.create_task` / `to_thread` children never inherit false reentrancy, and roll back multi-lock acquisition on `BaseException` (`CancelledError`).
- **Parent-Directory `.lifecycle_<id>.lock` & POSIX Inode Verification:** Acquire `<sessions_parent>/.lifecycle_<id>.lock` (`0_lifecycle`) before `<session_dir>/.session.lock` (`1_session`) in `reentrant_session_lock` so `force=True` directory swaps exclude session writers without open handles inside renamed directories; on POSIX, verify `fstat(fd)` matches `stat(path)` `(st_dev, st_ino)` after `flock`.
- **Magic-Byte/Filter Ingestion, Calc `Link=1` & Symlink-Free Bundles:** Enforce PKZIP vs OLE2 CFB magic-byte agreement + BIFF8 `SUPBOOK` blocking + Calc `Link=1` (`LM_NEVER`) + `--infilter` before `soffice` conversion; in `export_bundle`/`import_bundle`, reject symlinks/reparse points (`lstat` + `0x0400` + `O_NOFOLLOW` + streamed `zf.open`), Win32 trailing `.`/` ` & `~\d` segments, and out-of-studio API export paths when `OPENDV_WORKSPACE_ROOTS` is unset.
- **Locale-Safe Windows ACLs:** Enforce/verify owner-only permissions on Windows via Win32 `advapi32` binary SIDs (`S-1-5-18`, `S-1-5-32-544`, process token owner SID)—never parse localized `icacls.exe` text output.
- **Transactional `force=True` Swaps:** Stage into `<target>.staging.<nonce>`, move existing `<target>` to `<target>.tombstone.<nonce>`, swap staging into place, and restore tombstone on failure.
- **Process-Tree Cleanup & Local Binding:** Kill full process trees on subprocess timeouts (`taskkill /F /T` / `os.killpg`), quote `.cmd` variables (`set "VAR=val"`), and bind local dev servers to `127.0.0.1`.

## 3. Thread-Safe Async & Gapless W3C SSE
- **No Cross-Thread `asyncio.Queue` Calls:** From worker threads, publish events exclusively via `loop.call_soon_threadsafe(...)` on a bound `(loop, queue)` pair.
- **Subscribe Before Replay:** Register the live queue subscriber *before* reading `events.jsonl` from disk, then deduplicate live events with `seq <= last_replayed_seq` for gapless, duplicate-free SSE streams.
- **Client Job Tracking:** Every `202 Accepted` async job (`parse`, `clarify`, `construct`) must connect to `/jobs/{job_id}/events` (with polling fallback) and close cleanly on terminal state or session switch.

## 4. Cross-Surface Contract Parity (`extra="forbid"`)
- **Single Source of Truth & Compiled Binaries:** Register CLI flags in `schemas/v1/cli-spec.json` with `allow_abbrev=False` on Python `ArgumentParser` (so prefix matching never masks rejected flags like `--waiver-key`), rebuild `apps/opendvctl/dist/release/opendvctl-windows-x64.exe` whenever `cli-spec.json` or `apps/opendvctl/src` changes (`ClientCliTransport` executes that binary when present), keep `set(ErrorCode) == set(error-codes.json)`, and keep governance constants unified across backend, CLIs, SPA, and docs.
- **Exact Wire Payloads & Security Headers:**
  - Route all Web Workbench requests through `studioFetch` (`credentials: "include"`, `X-OpenDV-Workbench: 1` on `POST`/`PUT`/`PATCH`/`DELETE`, `Authorization: Bearer` when token-authenticated).
  - Pass `OPENDV_WAIVER_KEY` via `X-OpenDV-Waiver-Key` header—never in JSON request bodies.
  - Match `extra="forbid"` DTOs: `do_not_send_to_agent` on source uploads; `op_id` on every delta op; `mapping_confidence` (no `provenance`) on `add_external_mapping`; `selected_options` + `user_text` + `expected_answers_sha256` (`If-Match`) on `/answers`; `0.0.0 -> 1.0.0` when `add_concept` is present on genesis commits.
  - **Client OCC Baseline Pinning, SPA Summary Merges & Explicit Role Headers:** CLI and SPA clients must never auto-fetch current server `head_sha256` to populate `If-Match` over a stale local delta or dirty working canvas; merging `StudioSessionSummaryDTO` (`GET /sessions`) must preserve `activeSession.head_sha256`; SPA `commitChanges` must classify SemVer bumps identically to `validator.py` and scope `ONT-EVO-002` pre-checks to delta-touched concepts; and `RemoteExecutor` must only send `X-OpenDV-Role` on Studio endpoints when `--role` / `OPENDV_ROLE` was explicitly supplied (never defaulting to `INTERNAL_MODELER`, which downgrades `.local_token` human sessions to `automated`).
  - **Shared `DeploymentStateProvider` Across All Surfaces:** Wire `build_workspace_deployment_provider(workspace_root)` uniformly across local CLI, FastAPI Studio routes (`/validate`, `/delta`, `/accept`, `/rebase`, `/promote`), and `AtomicCommitService` auto-commits (skipping monorepo `packages`/`apps`/`tests`/`vendor` directories when scanning the `open-dv` repo root).
- **Untrusted Ontology Text in Exporters & Docs:** Treat LLM/PDF labels, URIs, and descriptions as untrusted input—validate identifiers, sanitize quotes and comment delimiters, and test doc snippets in `tests/docs/test_doc_code_snippets.py`.

## 5. Fail-Closed Governance, Sticky Privacy & Audit Chains
- **Strict `ONT-EVO-002` Grounding & Attribute SemVer Parity:** Grounded iff a server-verified `FIBO` mapping uses `skos:exactMatch` or `skos:closeMatch` (`skos:broadMatch` excluded!) with numeric `confidence >= 0.6500` (never self-inject FIBO synonyms onto uncurated `preferred_mappings` before verification; stage with `PREFERRED_MAPPING_REQUIRES_WAIVER`). Rate `RefineDefinitionOp.additional_attributes` (`MINOR`/`MAJOR`) and `AddConceptOp` merges (`MAJOR` mandatory) identically to `AddAttributeOp`, and resolve slug-matched caller enums to actual base `enum_uri`s.
- **Trusted Server Context Overrides Only:** Internal privilege or migration flags (`allow_bootstrap`, `allow_legacy_ip1_bootstrap`, `allow_cli_output_path`) must be set exclusively by trusted server/CLI call sites—never auto-enabled from caller-controlled request payloads or metadata.
- **`snake_case`-Safe Redaction, Serialized `Mapping` Privacy & Fail-Closed Taint:** Use `(?<![A-Za-z0-9])...(?![A-Za-z0-9])` (never `\b`) over `sensitive_terms | sensitive_entities`, enforce `do_not_send_to_agent`/`pseudonymized=True` on serialized `model_dump()` dicts as well as models, and raise `CORRUPT_SESSION_RECORD` (never `contextlib.suppress`) on corrupt `taint_index.json` or `inputs/manifest.json`.
- **Signed WAL `COMMITTED` Roll-Forward, Waiver Binding & Fail-Closed Rebase:** Roll forward `K_audit`-verified `COMMITTED` / `PROMOTION_COMMITTED` WAL entries into `session.json` before orphan quarantine, verify `staged_ont` SHA-256 against `session.head_sha256`, gate forward recovery on an active `PENDING_COMMIT` intent, verify imported `v0.0.0` roots against genuine genesis SHA-256, bind waivers to `proposal_delta_sha256`, latch `commit_started` against late job cancels, and fail closed on missing/corrupt `rebase` deltas.

## 6. Multi-Agent Repository Hygiene & Cross-Platform CI Parity
- Never commit subagent context notes, critique JSON/MD dumps, or one-off issue scripts into `scripts/`, `reports/`, or the repo root. Keep scratch files in harness scratch storage or `.critique/`, and verify `git status --short` before finishing.
- **Monorepo-Root & Ubuntu CI Parity:** Never call `Path.resolve()`/`Path.exists()` inside a monkeypatched `os.stat` (on Python 3.12 POSIX both invoke `os.stat` and recurse infinitely). In Bun tests, resolve paths via `import.meta.dir` (never CWD-relative `Bun.file("../../...")`), guard `uv` subprocess checks with `Bun.which("uv")` for pure-Bun CI runners, spawn `bun build` in a child CLI process rather than calling programmatic `Bun.build()` repeatedly inside one Linux `bun test` worker, and always run `bun run --cwd packages/opendv-protocol-ts codegen` after `openapi-v1.json` updates.

## 7. Web Workbench E2E, Dark-Mode UI, RBAC Hydration & Constants Hygiene
- **Dark-Mode React Flow & Drawer Layout CSS:** Always override vendored React Flow CSS variables (`--xy-controls-button-*`, `--xy-minimap-*`) and add explicit `.canvas-flow-wrapper .react-flow__controls*` (`svg { fill: currentColor; }`) + `.react-flow__minimap*` rules so dark-mode zoom/minimap controls maintain `>= 4.5:1` contrast. Stack `.panel-header` vertically (`flex-direction: column`) in narrow drawer tabs while keeping `.sessions-list-panel .panel-header` horizontal; constrain `.mapping-tag` (`text-overflow: ellipsis; overflow: hidden`) inside `.concept-node { overflow: hidden; }`; and extract terminal IRI fragments via `.split(/[\/#:]/).filter(Boolean).pop()` (with full-IRI `title` tooltips) instead of `.split(":").pop()`.
- **RBAC Role Hydration & 409 Loopback Bootstrap UX:** Return `role` on `InitStudioResponse` and `TokenExchangeResponse`, attach `request.state.studio_principal` across `init_studio`, `exchange_launch_nonce_endpoint`, and all four RBAC dependencies (`require_viewer`..`require_admin`, before raising `403`), and expose/attach `X-OpenDV-Role` and `X-OpenDV-Principal` in `CORSMiddleware` + request middleware so SPA state hydrates accurately from its default `"editor"` fallback into `"admin"`, `"editor"`, `"viewer"`, or `"automated"`. On HTTP `409` (`STUDIO_ALREADY_INITIALIZED`), focus the token input and surface `.opendv/ontology_studio/.local_token` / `opendv serve --open` instructions cleanly.
- **Session Recency, Working Draft Diffs, 0-Op Guard & Centralized Constants:** Sort `StudioSessionManager.list_sessions()` by `(updated_at or created_at, session_id)` descending; normalize `.md`/`.markdown` `application/octet-stream` uploads to `"text/markdown"`; synthesize `"draft"` snapshots directly from in-memory canvas nodes/edges inside `loadAndComputeDiff`; disable Accept (keeping Reject enabled for cleanup) when `operations.length === 0`; and centralize UI constants (`STUDIO_MAX_UPLOAD_BYTES`, `GROUNDING_MIN_CONFIDENCE`, etc.) in `apps/opendv-web-workbench/src/ontology/constants.ts`.
