## Quick Non-Negotiable Reminders
- **Zero Production Mocks / Silent Fallbacks & Agent-Only UI (`D28`):** Fail closed and loudly with typed `ErrorCode` diagnostics (`schemas/v1/error-codes.json`, including `422 AGENT_NOT_CONFIGURED`). Never silently swallow server errors, substitute lossy client-side fallbacks, or expose a deterministic mode toggle in the Web Workbench UI (`--mode deterministic` is CLI/API-only for offline CI).
- **Loopback Open Access & Remote Guard (`D18`):** Loopback requests run auth-free (`human:local_user` / `admin`) with zero token/cookie/CSRF login steps; `opendv serve` / `opendv-platform` refuse non-loopback `--host` with exit code `40` unless `--allow-remote-unauthenticated` is explicitly supplied.
- **Cross-Transport Parity & Unified Workbench Routes:** Standalone `opendv` (Python), remote `opendvctl` (Bun/TS), FastAPI (`/api/v1/...`), the 4-tab `:8420` Web Workbench (`/`, `/ontology`, `/builder` -> Unified 6-Step Wizard; `/dv-schema` -> 4-View DV Schema Explorer; `/explorer`, `/stages/00..07` -> Run Explorer; `/settings` -> Settings) using the **5-Zone (`Z0–Z4`)** + `information_mart` UI standard (preserving `compiler_4zone` / `final_four_zone.sql` internal parity names), and executable documentation (`docs/22`, `docs/23`) must agree on `schemas/v1/cli-spec.json`, `extra="forbid"` Pydantic DTOs, and canonical RFC 8785 JCS SHA-256 digests (`0.0.0` genesis = `1916a5c6d501015984b887fd76609b225b72d5d393e5813d8df210b92ab3b4c9`).
